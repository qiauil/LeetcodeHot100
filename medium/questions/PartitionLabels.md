# 题目：划分字母区间（Partition Labels）

给定一个只包含小写英文字母的字符串 `s`。

将字符串划分成**尽可能多**的子字符串，并保证：

> 同一个字母最多只能出现在其中一个子字符串中。

返回一个整数列表，表示各个子字符串的长度。

------

## 1. 贪心 + 区间边界

### 核心思路

关键约束是：

> 如果某个字符出现在当前分区，那么这个字符的**所有出现位置**都必须属于当前分区。

例如，当前分区出现了 `a`，而 `a` 最后一次出现在索引 `8`，那么当前分区至少必须延伸到 `8`。

因此可以先记录每个字符**最后一次出现的位置**，然后从左向右扫描字符串。

用 `end` 表示：

> 当前分区中已经出现的所有字符，其“最后出现位置”的最大值。

每遇到字符 `c`：

```
end = max(end, last_index[c])
```

当：

```
i == end
```

说明当前分区里的所有字符以后都不会再出现，因此可以安全切分。

而题目要求分区数量尽可能多，所以**一旦可以切分，就立即切分**。这就是贪心策略。

------

## 2. 算法步骤

1. 第一次遍历字符串，记录每个字符最后一次出现的索引 `last_index`。
2. 初始化：
   - `res`：保存每个分区的长度；
   - `size`：当前分区长度；
   - `end`：当前分区必须到达的最远位置。
3. 第二次遍历字符串：
   - `size += 1`
   - `end = max(end, last_index[c])`
4. 如果 `i == end`：
   - 当前分区结束；
   - 将 `size` 加入 `res`；
   - 将 `size` 重置为 `0`。
5. 返回 `res`。

------

## 3. Python 实现

```
from typing import List


class Solution:
    def partitionLabels(self, s: str) -> List[int]:
        # last_index[c]：字符 c 最后一次出现的位置
        last_index = {}

        # 第一次遍历：
        # 相同字符的索引会不断被覆盖，
        # 最终留下的就是它最后一次出现的位置
        for i, c in enumerate(s):
            last_index[c] = i

        res = []
        size = 0  # 当前分区长度
        end = 0   # 当前分区必须到达的最远位置

        # 第二次遍历
        for i, c in enumerate(s):
            size += 1

            # 当前字符如果在更远的位置还会出现，
            # 当前分区必须扩展到那里
            end = max(end, last_index[c])

            # 已到达当前分区中所有字符的最远最后位置
            if i == end:
                res.append(size)
                size = 0

        return res
```

## 4. 示例理解

假设：

```
s = "ababcbacadefegdehijhklij"
```

从左向右扫描。

首先：

```
i = 0, c = 'a'
a 最后出现在 8
end = 8
```

接着：

```
i = 1, c = 'b'
b 最后出现在 5
end = max(8, 5) = 8
```

之后遇到 `c`：

```
c 最后出现在 7
end = max(8, 7) = 8
```

当扫描到：

```
i = 8
```

此时 `i == end`，说明 `[0, 8]` 中出现的 `a、b、c` 在后面都不会再次出现。

所以第一个分区是：

```
ababcbaca
```

长度为 `9`。

继续使用相同的方法，最终得到：

```
[9, 7, 8]
```

------

## 5. 为什么贪心是正确的？

贪心选择是：

> **只要当前区间已经可以合法结束，就立即结束。**

当 `i == end` 时，当前区间中所有字符最后一次出现的位置都不超过 `i`，所以这些字符以后不会再出现。

如果此时不切分，而继续向右扩展，虽然答案仍然可能合法，但只会让当前分区更大，从而减少最终可能得到的分区数量。

因此：

> **最早可以合法切分的位置，就是当前最优的切分位置。**

------

## 6. `end` 的本质：动态右边界

`end` 是这道题最重要的变量。

每遇到一个字符，都可以理解为它提出了一个要求：

> “既然当前分区包含了我，那么至少要包含到我最后一次出现的位置。”

例如：

```
a 最后出现在 8
b 最后出现在 5
c 最后出现在 7
```

那么当前区间至少要延伸到：

```
max(8, 5, 7) = 8
```

如果途中又遇到一个字符，它最后出现在 `12`，那么：

```
end = 12
```

当前区间就必须继续扩展。

这也可以理解成一种**区间合并**：每个字符都有一个

```
[第一次出现的位置, 最后一次出现的位置]
```

例如：

```
a -> [0, 8]
b -> [1, 5]
c -> [4, 7]
```

这些区间互相重叠，因此必须属于同一个分区 `[0, 8]`。

原算法实际上是在扫描过程中隐式完成区间合并，因此不需要真的构造这些区间。

## 7. Python 相关知识

### `enumerate()`

```
for i, c in enumerate(s):
```

`enumerate()` 可以同时获得元素的索引和值。

例如：

```
s = "abc"

for i, c in enumerate(s):
    print(i, c)
```

输出：

```
0 a
1 b
2 c
```

相比：

```
for i in range(len(s)):
    c = s[i]
```

`enumerate()` 更简洁，也是 Python 面试中非常常见的写法。

### `dict`

```
last_index = {}
```

创建 Python 字典，用于保存：

```
字符 -> 最后一次出现的位置
```

例如：

```
{
    'a': 8,
    'b': 5,
    'c': 7
}
```

由于：

```
last_index[c] = i
```

会不断覆盖同一个字符之前的索引，因此最终自然得到它最后一次出现的位置。

### `max()`

```
end = max(end, last_index[c])
```

表示在“当前右边界”和“当前字符最后出现的位置”之间选择更大的值。

因此 `end` 只会保持不变或向右扩展，不会向左缩小。

## 8. 时间与空间复杂度

### 时间复杂度：`O(n)`

字符串遍历两次：

```
第一次：记录最后出现位置
第二次：寻找分区边界
```

因此：

```
O(n) + O(n) = O(n)
```

其中 `n` 是字符串长度。

### 空间复杂度：`O(1)`

题目规定字符串只包含 26 个小写英文字母，因此 `last_index` 最多只有 26 个键值对，与 `n` 无关，所以额外空间可以认为是：

```
O(1)
```

更一般地，如果字符集大小为 `m`，则空间复杂度为 `O(m)`。

# 常见错误

### 1. 没有预计算最后出现位置

如果每遇到一个字符，都重新向后搜索它最后一次出现的位置，最坏情况下时间复杂度会退化为：

```
O(n²)
```

提前预处理：

```
for i, c in enumerate(s):
    last_index[c] = i
```

之后查询 `last_index[c]` 平均只需要 `O(1)`。

### 2. 忘记重置 `size`

完成一个分区后：

```
if i == end:
    res.append(size)
    size = 0
```

必须把 `size` 重置，否则下一段会累加上一段的长度。

### 3. Off-by-One 错误

正确条件是：

```
if i == end:
```

因为 `end` 本身就是当前分区包含的最后一个索引。

例如 `[0, 8]` 包含：

```
8 - 0 + 1 = 9
```

个字符，所以扫描到索引 `8` 时，分区已经结束。

### 4. 错误地直接覆盖 `end`

错误：

```
end = last_index[c]
```

正确：

```
end = max(end, last_index[c])
```

例如：

```
a 最后出现在 10
b 最后出现在 5
```

遇到 `a` 后已经有：

```
end = 10
```

之后即使遇到 `b`，也不能把 `end` 缩短为 `5`，否则会过早切分。

## 面试记忆版

可以把整道题记成一句话：

> **先记录每个字符最后出现的位置；再从左向右扫描，用 `end` 维护当前分区中所有字符的最远最后位置；当 `i == end` 时立即切分。**

核心代码：

```
last_index = {c: i for i, c in enumerate(s)}

res = []
size = end = 0

for i, c in enumerate(s):
    size += 1
    end = max(end, last_index[c])

    if i == end:
        res.append(size)
        size = 0
```

核心贪心逻辑：

> **当前区间必须包含其中所有字符的最后一次出现位置；一旦到达最远的最后出现位置，就立即切分。**
