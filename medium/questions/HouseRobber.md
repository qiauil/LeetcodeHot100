# 打家劫舍（House Robber）

给定一个整数数组 `nums`，其中 `nums[i]` 表示第 `i` 间房屋中存放的金额。

所有房屋沿直线排列，因此第 `i` 间房屋与第 `i - 1` 间、第 `i + 1` 间房屋相邻。

你计划偷窃这些房屋，但不能同时偷窃两间相邻的房屋，否则安全系统会自动报警。

请返回在不触发警报的情况下，能够偷窃到的最大金额。

## 核心思路

对于每一间房屋，我们都有两种选择：

- 不偷当前房屋：保留偷窃前一间房屋时得到的最优结果。
- 偷当前房屋：获得当前房屋的金额，但不能偷前一间房屋。

因此，问题的核心状态转移关系为：

```
当前最优结果 = max(
    不偷当前房屋的结果,
    偷当前房屋的结果
)
```

如果使用自底向上的动态规划，并定义：

```
dp[i] = 从第 0 间到第 i 间房屋能够偷到的最大金额
```

那么状态转移方程就是：

```
dp[i] = max(dp[i - 1], nums[i] + dp[i - 2])
```

其中：

- `dp[i - 1]`：不偷第 `i` 间房屋。
- `nums[i] + dp[i - 2]`：偷第 `i` 间房屋，因此必须跳过第 `i - 1` 间。

------

## 1. 递归

### 思路

从第 `i` 间房屋开始，我们可以：

- 跳过当前房屋，继续考虑第 `i + 1` 间房屋。
- 偷当前房屋，然后跳过相邻房屋，继续考虑第 `i + 2` 间房屋。

递归会尝试这两种选择，并返回其中金额较大的结果。

### 算法步骤

1. 从下标 `0` 开始。
2. 对于下标 `i`：
   - 不偷当前房屋：计算 `dfs(i + 1)`。
   - 偷当前房屋：计算 `nums[i] + dfs(i + 2)`。
3. 返回两种选择中的较大值。
4. 如果 `i` 超出数组范围，说明已经没有房屋可以偷，返回 `0`。

```
from typing import List


class Solution:
    def rob(self, nums: List[int]) -> int:
        def dfs(i: int) -> int:
            # 已经越过最后一间房屋
            if i >= len(nums):
                return 0

            # 选择一：跳过当前房屋
            skip = dfs(i + 1)

            # 选择二：偷当前房屋，并跳过下一间房屋
            take = nums[i] + dfs(i + 2)

            return max(skip, take)

        return dfs(0)
```

### 复杂度分析

- 时间复杂度：`O(2^n)`
- 空间复杂度：`O(n)`

递归树中，每个状态最多产生两个分支，因此最坏情况下时间复杂度是指数级别。递归调用栈的最大深度为 `O(n)`。

> 这种方法适合理解问题，但由于会重复计算大量相同的子问题，通常无法通过较大的测试数据。

------

## 2. 动态规划：自顶向下（记忆化搜索）

### 思路

普通递归会反复计算相同的子问题。例如，`dfs(2)` 可能通过不同的递归路径被多次调用。

可以使用一个数组保存已经计算过的结果：

```
memo[i] = 从第 i 间房屋开始，能够偷到的最大金额
```

当再次遇到相同的 `i` 时，直接返回保存的结果，不再重复计算。

### 算法步骤

1. 创建记忆数组 `memo`。
2. 定义递归函数 `dfs(i)`：
   - 如果 `i` 越界，返回 `0`。
   - 如果 `memo[i]` 已经计算过，直接返回。
   - 分别计算跳过当前房屋和偷当前房屋的结果。
   - 将较大值保存到 `memo[i]`。
3. 从 `dfs(0)` 开始计算。

```
from typing import List


class Solution:
    def rob(self, nums: List[int]) -> int:
        # None 表示该状态尚未计算
        memo = [None] * len(nums)

        def dfs(i: int) -> int:
            # 没有剩余房屋
            if i >= len(nums):
                return 0

            # 直接使用之前计算过的结果
            if memo[i] is not None:
                return memo[i]

            skip = dfs(i + 1)
            take = nums[i] + dfs(i + 2)

            memo[i] = max(skip, take)
            return memo[i]

        return dfs(0)
```

### 为什么使用 `None`

原代码使用 `-1` 表示尚未计算。由于题目中的金额通常是非负整数，这种写法是安全的。

使用 `None` 会更加通用，因为它明确表示“尚未计算”，不会与合法的数值结果混淆。

### 复杂度分析

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

每个下标只会被真正计算一次。额外空间包括：

- `memo` 数组：`O(n)`
- 递归调用栈：`O(n)`

------

## 3. 动态规划：自底向上

### 思路

我们也可以避免递归，按照从左到右的顺序逐步计算答案。

定义：

```
dp[i] = 从第 0 间到第 i 间房屋能够偷到的最大金额
```

对于第 `i` 间房屋：

- 如果不偷它，结果是 `dp[i - 1]`。
- 如果偷它，就不能偷第 `i - 1` 间，结果是 `nums[i] + dp[i - 2]`。

因此：

```
dp[i] = max(dp[i - 1], nums[i] + dp[i - 2])
```

### 算法步骤

1. 处理空数组和只有一间房屋的情况。
2. 创建数组 `dp`。
3. 初始化：
   - `dp[0] = nums[0]`
   - `dp[1] = max(nums[0], nums[1])`
4. 从下标 `2` 开始应用状态转移方程。
5. 返回 `dp[n - 1]`。

```
from typing import List


class Solution:
    def rob(self, nums: List[int]) -> int:
        # 没有房屋
        if not nums:
            return 0

        # 只有一间房屋
        if len(nums) == 1:
            return nums[0]

        # dp[i] 表示前 i + 1 间房屋中能够偷到的最大金额
        dp = [0] * len(nums)

        dp[0] = nums[0]
        dp[1] = max(nums[0], nums[1])

        for i in range(2, len(nums)):
            # 不偷当前房屋：dp[i - 1]
            # 偷当前房屋：nums[i] + dp[i - 2]
            dp[i] = max(dp[i - 1], nums[i] + dp[i - 2])

        return dp[-1]
```

### 复杂度分析

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

数组中的每间房屋只被处理一次，并使用一个长度为 `n` 的 DP 数组。

## 4. 动态规划：空间优化

### 思路

观察状态转移方程：

```
dp[i] = max(dp[i - 1], nums[i] + dp[i - 2])
```

计算 `dp[i]` 时，只需要：

- `dp[i - 1]`
- `dp[i - 2]`

因此不需要保存完整的 DP 数组，只需要使用两个变量记录最近的两个状态。

可以定义：

- `prev2`：处理当前房屋前的 `dp[i - 2]`。
- `prev1`：处理当前房屋前的 `dp[i - 1]`。

### 算法步骤

对于每间房屋的金额 `money`：

1. 不偷当前房屋：结果为 `prev1`。
2. 偷当前房屋：结果为 `prev2 + money`。
3. 当前最优结果为二者的最大值。
4. 更新两个历史状态。

```
from typing import List


class Solution:
    def rob(self, nums: List[int]) -> int:
        # prev2：相当于 dp[i - 2]
        # prev1：相当于 dp[i - 1]
        prev2 = 0
        prev1 = 0

        for money in nums:
            # 不偷当前房屋：prev1
            # 偷当前房屋：prev2 + money
            current = max(prev1, prev2 + money)

            # 状态向前移动
            prev2 = prev1
            prev1 = current

        return prev1
```

### 复杂度分析

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

这是本题最推荐的实现：既保持了动态规划的线性时间复杂度，又将额外空间降低到了常数级别。

即使 `nums` 是空数组，循环也不会执行，最终会自然返回 `0`，因此这个版本不需要单独判断空数组。

------

## 示例推演

假设：

```
nums = [2, 7, 9, 3, 1]
```

使用空间优化的动态规划：

| 当前金额 | 偷当前房屋    | 不偷当前房屋 | 当前最大金额 |
| -------- | ------------- | ------------ | ------------ |
| 2        | `0 + 2 = 2`   | 0            | 2            |
| 7        | `0 + 7 = 7`   | 2            | 7            |
| 9        | `2 + 9 = 11`  | 7            | 11           |
| 3        | `7 + 3 = 10`  | 11           | 11           |
| 1        | `11 + 1 = 12` | 11           | 12           |

最终答案为：

```
12
```

对应偷窃第 `0`、`2`、`4` 间房屋：

```
2 + 9 + 1 = 12
```

## 常见错误

### 1. 错误初始化 `dp[1]`

正确写法是：

```
dp[1] = max(nums[0], nums[1])
```

而不是：

```
dp[1] = nums[1]
```

`dp[1]` 表示前两间房屋中能够偷到的最大金额。因为两间房屋相邻，只能选择其中金额较大的一间。

例如：

```
nums = [10, 1]
```

正确答案应该是 `10`，而不是 `1`。

### 2. 混淆状态转移方程

正确的状态转移方程是：

```
dp[i] = max(dp[i - 1], nums[i] + dp[i - 2])
```

常见的错误写法是：

```
dp[i] = max(dp[i - 1] + nums[i], dp[i - 2])
```

`dp[i - 1]` 可能已经包含第 `i - 1` 间房屋。如果再加上 `nums[i]`，就可能同时偷窃两间相邻房屋，违反题目要求。

### 3. 没有处理边界情况

使用 DP 数组时，需要特别处理：

```
if not nums:
    return 0

if len(nums) == 1:
    return nums[0]
```

否则，直接初始化 `dp[0]` 和 `dp[1]` 可能造成数组越界。

空间优化版本会自然处理这两种情况：

- 空数组最终返回 `0`。
- 单元素数组最终返回该元素。

### 4. 原地更新两个状态时顺序错误

下面的更新方式是正确的：

```
current = max(prev1, prev2 + money)
prev2 = prev1
prev1 = current
```

必须先计算并保存 `current`，再更新 `prev2` 和 `prev1`。如果过早修改其中一个变量，后续计算就可能使用错误的状态。

## Python 语法补充

### `List[int]`

```
from typing import List
```

`List[int]` 是类型提示，表示参数应该是一个由整数构成的列表：

```
def rob(self, nums: List[int]) -> int:
```

其中最后的 `-> int` 表示函数预期返回一个整数。

在 Python 3.9 及以上版本中，也可以写成：

```
def rob(self, nums: list[int]) -> int:
```

类型提示主要用于提高代码可读性，并帮助编辑器或静态检查工具发现潜在错误；Python 运行时通常不会强制检查这些类型。

### `max()`

`max()` 用于返回多个值中的最大值：

```
best = max(skip, take)
```

在本题中，它恰好用来比较“不偷当前房屋”和“偷当前房屋”两种决策。

### `dp[-1]`

Python 允许使用负数下标访问列表：

```
dp[-1]
```

表示列表中的最后一个元素，等价于：

```
dp[len(dp) - 1]
```

## 面试总结

这道题是非常典型的动态规划问题。判断它适合使用动态规划的关键在于：

- 每间房屋都有“偷”或“不偷”两种选择。
- 当前选择会受到相邻房屋的约束。
- 大问题可以由较小的相同类型问题构成。
- 递归过程中会重复计算相同状态。

推荐在面试中按照以下顺序讲解：

1. 先说明每间房屋存在“偷”和“不偷”两种选择。

2. 写出状态定义：

   ```
   dp[i] = 前 i + 1 间房屋能够偷到的最大金额
   ```

3. 推导状态转移方程：

   ```
   dp[i] = max(dp[i - 1], nums[i] + dp[i - 2])
   ```

4. 说明初始状态和边界情况。

5. 最后指出当前状态只依赖前两个状态，因此可以把空间复杂度从 `O(n)` 优化为 `O(1)`。
