# 字符串解码（Decode String）

给定一个经过编码的字符串 `s`，返回它解码后的字符串。

编码规则如下：

```
k[encoded_string]
```

方括号中的 `encoded_string` 需要重复恰好 `k` 次，其中 `k` 保证是正整数。

可以假设输入字符串始终有效：

- 不包含多余空格。
- 方括号一定正确匹配。
- 不会出现 `3a`、`2[4]`、`a[a]` 或 `a[2]` 等非法输入。
- 测试数据保证解码后的字符串长度不超过 `100,000`。

例如：

```
输入：s = "3[a2[c]]"
输出："accaccacc"
```

解码过程：

```
2[c]       -> "cc"
a2[c]      -> "acc"
3[a2[c]]   -> "accaccacc"
```

## 前置知识

解决本题前，建议熟悉以下内容：

- **递归**：通过函数调用自身处理嵌套结构。
- **栈**：保存外层状态，以迭代方式模拟递归。
- **字符串处理**：解析多位数字、拼接字符串以及重复子字符串。

------

## 解法一：递归

### 核心思路

编码字符串具有天然的递归结构：

```
k[encoded_string]
```

其中 `encoded_string` 内部还可能包含另一个编码结构。

遇到左括号 `[` 时，可以递归解码括号中的内容；遇到右括号 `]` 时，说明当前递归层结束，将本层结果返回给上一层。

例如：

```
3[a2[c]]
```

递归关系可以理解为：

```
decode("3[a2[c]]")
    └── decode("a2[c]")
            └── decode("c")
```

### 算法步骤

1. 使用共享下标 `self.i` 记录当前读取位置。
2. 定义递归函数 `helper()`：
   - `res` 保存当前层已经解码的字符串。
   - `k` 保存当前解析到的重复次数。
3. 遍历字符串：
   - 遇到数字时，将其累积到 `k` 中。
   - 遇到 `[` 时：
     - 将下标移动到括号内部。
     - 递归解码内部字符串。
     - 将结果重复 `k` 次后加入 `res`。
     - 将 `k` 重置为 `0`。
   - 遇到 `]` 时，返回当前层的结果。
   - 遇到普通字母时，直接加入 `res`。
4. 返回最外层递归结果。

### 代码

```
class Solution:
    def decodeString(self, s: str) -> str:
        # self.i 是所有递归层共享的读取位置
        self.i = 0

        def helper() -> str:
            res = ""
            k = 0

            while self.i < len(s):
                c = s[self.i]

                if c.isdigit():
                    # 支持多位数，例如：
                    # 12[a] -> k = 1 -> 12
                    k = k * 10 + int(c)

                elif c == "[":
                    # 跳过左括号，使递归从括号内部开始
                    self.i += 1

                    inner = helper()
                    res += inner * k

                    # 当前重复次数已经使用完毕
                    k = 0

                elif c == "]":
                    # 当前递归层结束
                    return res

                else:
                    # 普通字母直接加入结果
                    res += c

                self.i += 1

            return res

        return helper()
```

### 复杂度分析

设：

- `n` 为编码字符串的长度。
- `N` 为解码后字符串的长度。
- `d` 为最大括号嵌套深度。

在通常的算法分析中：

- 时间复杂度：`O(n + N)`
- 空间复杂度：`O(N + d)`

递归调用栈最多需要 `O(d)` 空间，最终结果需要 `O(N)` 空间。

需要注意，Python 字符串不可变，代码中的 `res += ...` 可能反复复制已有内容，因此在极端情况下，实际时间复杂度可能退化。面试中通常仍将该算法描述为 `O(n + N)`，但可以说明使用列表保存片段后统一 `join()` 能减少重复复制。

## 解法二：单栈

### 核心思路

可以使用一个栈保存已经读取的字符。

遇到普通字符、数字或左括号时，直接压入栈中。遇到右括号 `]` 时：

1. 弹出字符，直到找到对应的 `[`，得到括号内的字符串。
2. 弹出 `[`。
3. 继续向前弹出所有连续数字，得到重复次数。
4. 将子字符串重复指定次数，再压回栈中。

这种方法实际上是利用栈从内向外逐层解码。

### 算法步骤

1. 初始化空栈 `stack`。
2. 遍历字符串中的每个字符：
   - 如果不是 `]`，直接压栈。
   - 如果是 `]`：
     - 弹出括号内的字符串。
     - 删除对应的 `[`。
     - 弹出左侧连续数字，组成重复次数 `k`。
     - 将子字符串重复 `k` 次后压回栈中。
3. 将栈中所有字符串连接起来。

### 代码

```
class Solution:
    def decodeString(self, s: str) -> str:
        stack = []

        for c in s:
            if c != "]":
                # 数字、字母和左括号都先压入栈中
                stack.append(c)
                continue

            # 遇到右括号，提取括号内部的字符串
            substr = ""

            while stack[-1] != "[":
                # 栈是逆序弹出的，因此要把字符放在 substr 前面
                substr = stack.pop() + substr

            # 删除左括号
            stack.pop()

            # 提取左括号前面的重复次数
            count = ""

            while stack and stack[-1].isdigit():
                # 数字同样是逆序弹出的
                count = stack.pop() + count

            # 解码当前括号，并将结果放回栈中
            stack.append(substr * int(count))

        return "".join(stack)
```

### 复杂度分析

通常可以记为：

- 时间复杂度：`O(n + N²)`
- 空间复杂度：`O(n + N)`

出现平方级时间复杂度的主要原因是：

```
substr = stack.pop() + substr
```

每次都在字符串前面添加字符。由于 Python 字符串不可变，每次拼接都可能复制整个 `substr`，因此一个长度为 `m` 的子字符串可能需要 `O(m²)` 时间构造。

此外，解码结果在嵌套结构中可能被多次创建和复制。因此，这种单栈写法虽然直观，但通常不如双栈方法简洁、高效。

## 解法三：双栈

### 核心思路

使用两个栈分别保存：

- `string_stack`：进入当前括号前已经构造好的字符串。
- `count_stack`：当前括号对应的重复次数。

另外维护：

- `cur`：当前括号层正在构造的字符串。
- `k`：当前正在解析的重复次数。

遇到 `[` 时，将当前状态保存到栈中，然后开始处理新的内层字符串。遇到 `]` 时，取出外层状态，将当前字符串重复后拼接回外层字符串。

例如处理：

```
3[a2[c]]
```

关键状态变化如下：

```
读取 3[：
string_stack = [""]
count_stack  = [3]
cur = ""

读取 a2[：
string_stack = ["", "a"]
count_stack  = [3, 2]
cur = ""

读取 c]：
cur = "a" + "c" * 2 = "acc"

读取最后一个 ]：
cur = "" + "acc" * 3 = "accaccacc"
```

### 算法步骤

1. 初始化字符串栈和次数栈。
2. 使用 `cur` 保存当前字符串，使用 `k` 保存当前重复次数。
3. 遍历每个字符：
   - 数字：更新 `k = k * 10 + 当前数字`。
   - `[`：保存当前的 `cur` 和 `k`，然后重置二者。
   - `]`：弹出外层字符串和重复次数，完成当前层解码。
   - 普通字母：追加到 `cur`。
4. 遍历结束后返回 `cur`。

### 代码

```
class Solution:
    def decodeString(self, s: str) -> str:
        # 保存进入每层括号之前的字符串
        string_stack = []

        # 保存每层括号对应的重复次数
        count_stack = []

        # 当前括号层已经构造出的字符串
        cur = ""

        # 当前正在解析的重复次数
        k = 0

        for c in s:
            if c.isdigit():
                # 累积多位数，例如 12：
                # 先得到 1，再得到 1 * 10 + 2 = 12
                k = k * 10 + int(c)

            elif c == "[":
                # 保存进入括号前的状态
                string_stack.append(cur)
                count_stack.append(k)

                # 开始构造括号内部的字符串
                cur = ""
                k = 0

            elif c == "]":
                # 当前括号内部的解码结果
                inner = cur

                # 恢复外层字符串和当前层的重复次数
                previous = string_stack.pop()
                count = count_stack.pop()

                # 将当前层结果拼接回外层
                cur = previous + inner * count

            else:
                # 普通字母直接加入当前字符串
                cur += c

        return cur
```

### 复杂度分析

在常见的算法模型下：

- 时间复杂度：`O(n + N)`
- 空间复杂度：`O(N + d)`

其中 `d` 是最大嵌套深度。

双栈最多保存每一层括号对应的字符串状态和重复次数。最终解码字符串占用 `O(N)` 空间。

严格考虑 Python 不可变字符串的复制成本时，多次使用 `cur += c` 或拼接较大的字符串，极端情况下也可能产生额外开销。不过在本题常见数据范围和面试语境中，通常将双栈解法视为 `O(n + N)`，也是最推荐掌握的迭代解法。

## Python 相关函数与操作说明

### `str.isdigit()`

```
c.isdigit()
```

用于判断字符串 `c` 是否由数字字符组成。

例如：

```
"7".isdigit()    # True
"a".isdigit()    # False
"12".isdigit()   # True
```

本题中每次检查的是单个字符：

```
if c.isdigit():
    ...
```

题目通常只包含 ASCII 数字 `0` 到 `9`。需要注意，`isdigit()` 也可能识别部分 Unicode 数字字符，但这不会影响本题。

### `int()`

```
int(c)
```

用于将数字字符串转换为整数：

```
int("7")   # 7
int("12")  # 12
```

如果传入非数字字符串，则会抛出 `ValueError`。

### 字符串重复

Python 可以使用乘法重复字符串：

```
"ab" * 3
```

结果为：

```
"ababab"
```

因此：

```
inner * count
```

可以直接生成重复 `count` 次的解码结果。

### `list.append()` 和 `list.pop()`

Python 的列表可以作为栈使用：

```
stack.append(value)  # 压栈
value = stack.pop()  # 弹出栈顶元素
```

`pop()` 默认删除并返回列表的最后一个元素，符合栈“后进先出”的特点。

### `"".join(...)`

```
"".join(stack)
```

用于将多个字符串一次性连接起来：

```
parts = ["ab", "cd", "ef"]
result = "".join(parts)
# "abcdef"
```

与循环中不断执行字符串加法相比，`join()` 通常更加高效。

## 常见错误

### 1. 没有处理多位数

重复次数不一定只有一位。例如：

```
12[a]
```

表示将 `"a"` 重复 12 次。

错误写法：

```
# 每次只读取当前一位数字
k = int(c)
```

正确写法：

```
# 将之前的数字左移一位，再加入当前数字
k = k * 10 + int(c)
```

以 `123` 为例：

```
k = 0
读取 1：k = 0 × 10 + 1 = 1
读取 2：k = 1 × 10 + 2 = 12
读取 3：k = 12 × 10 + 3 = 123
```

### 2. 使用后没有重置重复次数

处理完一个左括号后，必须将 `k` 重置为 `0`，否则它会影响后面的编码结构。

错误写法：

```
if c == "[":
    self.i += 1
    res += helper() * k
    # 忘记重置 k
```

正确写法：

```
if c == "[":
    self.i += 1
    res += helper() * k
    k = 0
```

双栈解法中同样需要重置：

```
elif c == "[":
    string_stack.append(cur)
    count_stack.append(k)

    cur = ""
    k = 0
```

### 3. 递归中的下标管理错误

使用共享下标递归时，必须先跳过 `[`，再进入递归。

错误写法：

```
if c == "[":
    # 此时 helper() 仍然会看到当前这个 [
    res += helper() * k
    self.i += 1
```

正确写法：

```
if c == "[":
    # 先移动到括号内部的第一个字符
    self.i += 1
    res += helper() * k
```

当递归函数遇到 `]` 时直接返回。返回上一层后，循环末尾的：

```
self.i += 1
```

负责跳过这个右括号。

### 4. 忘记保存外层字符串

以双栈解法处理：

```
a2[bc]
```

进入 `[` 时，必须保存已经读取的 `"a"`。否则解码完成后只能得到 `"bcbc"`，而不是正确的 `"abcbc"`。

```
string_stack.append(cur)
```

保存的就是进入括号前的外层字符串。

### 5. 单栈中字符顺序反转

栈按照后进先出的顺序弹出字符。

对于：

```
[abc]
```

弹出的顺序是：

```
c、b、a
```

所以不能写成：

```
substr += stack.pop()
```

否则会得到 `"cba"`。

应当写成：

```
substr = stack.pop() + substr
```

或者先将字符存入列表，最后反转并连接。

------

## 解法选择总结

- **递归**：最贴合题目的嵌套结构，容易理解，但需要仔细管理共享下标，并且嵌套过深时可能受到 Python 递归深度限制。
- **单栈**：思路直观，但数字、括号和字符串混合存储，解析过程较繁琐，字符串前置拼接还可能导致较高的时间开销。
- **双栈**：状态划分清晰，不需要手动从混合栈中提取数字，通常是面试中最推荐的迭代解法。

如果需要在面试中优先掌握一种方法，建议选择**双栈解法**；同时理解它实际上是在显式模拟递归调用栈。
