# 最长公共子序列

给定两个字符串 `text1` 和 `text2`，返回它们的最长公共子序列（Longest Common Subsequence，简称 LCS）的长度。如果不存在公共子序列，则返回 `0`。

**子序列**是指：从原序列中删除任意数量的元素（也可以一个都不删除），并且不改变剩余元素的相对顺序，所得到的新序列。

例如，`"cat"` 是 `"crabt"` 的子序列。

两个字符串的**公共子序列**，是指同时为这两个字符串子序列的字符串。

例如：

```
text1 = "abcde"
text2 = "ace"

最长公共子序列为 "ace"，长度为 3。
```

## 核心状态转移

设 `LCS(i, j)` 表示：

```
text1[i:] 与 text2[j:] 的最长公共子序列长度
```

其中 `text1[i:]` 表示从索引 `i` 开始直到字符串末尾的子串。

状态转移分为两种情况：

### 当前字符相同

如果：

```
text1[i] == text2[j]
```

那么这个字符可以加入公共子序列：

```
LCS(i, j) = 1 + LCS(i + 1, j + 1)
```

### 当前字符不同

此时至少需要放弃其中一个字符：

```
LCS(i, j) = max(
    LCS(i + 1, j),  # 跳过 text1[i]
    LCS(i, j + 1)   # 跳过 text2[j]
)
```

边界条件是：

```
如果任意一个字符串已经遍历结束，最长公共子序列长度为 0。
```

------

## 1. 递归

### 思路

从两个字符串的开头开始比较：

- 如果当前字符相同，就将其计入公共子序列，并同时移动两个索引。
- 如果当前字符不同，就分别尝试跳过 `text1` 或 `text2` 的当前字符，然后选择结果较大的分支。

这种方法直接体现了状态转移过程，但会重复计算大量相同的子问题。

### 算法步骤

1. 定义 `dfs(i, j)`，表示 `text1[i:]` 和 `text2[j:]` 的最长公共子序列长度。
2. 如果 `i` 或 `j` 到达对应字符串的末尾，返回 `0`。
3. 如果 `text1[i] == text2[j]`，返回 `1 + dfs(i + 1, j + 1)`。
4. 否则，尝试跳过任意一个当前字符，返回两个结果的最大值。
5. 最终答案为 `dfs(0, 0)`。

```
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        def dfs(i: int, j: int) -> int:
            # 只要有一个字符串遍历结束，就无法继续匹配
            if i == len(text1) or j == len(text2):
                return 0

            # 当前字符相同，将其加入公共子序列
            if text1[i] == text2[j]:
                return 1 + dfs(i + 1, j + 1)

            # 当前字符不同：
            # 1. 跳过 text1[i]
            # 2. 跳过 text2[j]
            # 选择结果较大的分支
            return max(
                dfs(i + 1, j),
                dfs(i, j + 1)
            )

        return dfs(0, 0)
```

### 复杂度分析

设：

- `m = len(text1)`
- `n = len(text2)`
- 时间复杂度：`O(2^(m+n))`
- 空间复杂度：`O(m+n)`

递归树的每个状态最多产生两个分支，因此时间复杂度为指数级。递归调用栈的最大深度不超过 `m+n`。

这种方法适合帮助理解递推关系，但通常无法通过较大规模的测试。

## 2. 记忆化搜索（自顶向下动态规划）

### 思路

普通递归会多次计算相同状态。例如，`dfs(2, 3)` 可能通过不同递归路径被重复调用。

可以使用字典记录已经计算过的 `(i, j)`：

- 第一次遇到某个状态时正常计算。
- 后续再次遇到时直接返回保存的答案。

一共有至多 `m × n` 个不同状态，因此可以将指数级时间复杂度降低为多项式级。

### 算法步骤

1. 创建字典 `memo`，用来保存每个 `(i, j)` 对应的答案。
2. 计算 `dfs(i, j)` 前，先检查该状态是否已经存在于 `memo`。
3. 如果存在，直接返回缓存结果。
4. 否则按照递归状态转移计算答案，并保存到 `memo`。
5. 返回 `dfs(0, 0)`。

```
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        # 键为 (i, j)，值为对应状态下的 LCS 长度
        memo = {}

        def dfs(i: int, j: int) -> int:
            # 边界条件：任意字符串遍历结束
            if i == len(text1) or j == len(text2):
                return 0

            # 如果该状态已经计算过，直接返回缓存结果
            if (i, j) in memo:
                return memo[(i, j)]

            if text1[i] == text2[j]:
                # 当前字符相同
                memo[(i, j)] = 1 + dfs(i + 1, j + 1)
            else:
                # 当前字符不同，尝试跳过其中一个字符
                memo[(i, j)] = max(
                    dfs(i + 1, j),
                    dfs(i, j + 1)
                )

            return memo[(i, j)]

        return dfs(0, 0)
```

### Python 字典说明

`memo` 是一个 Python 字典：

```
memo = {}
```

这里使用元组 `(i, j)` 作为键：

```
memo[(i, j)] = result
```

字典的查询和插入操作平均时间复杂度为 `O(1)`，因此非常适合实现记忆化搜索。

### 复杂度分析

- 时间复杂度：`O(m × n)`
- 空间复杂度：`O(m × n)`

共有 `m × n` 个可能的 `(i, j)` 状态，每个状态只会被真正计算一次。

空间主要包括：

- 最多 `O(m × n)` 的缓存；
- 最坏情况下深度为 `O(m+n)` 的递归调用栈。

整体空间复杂度由缓存主导，为 `O(m × n)`。

### 使用 `functools.cache` 的简化写法

Python 还可以使用 `functools.cache` 自动缓存递归函数的结果：

```
from functools import cache


class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        @cache
        def dfs(i: int, j: int) -> int:
            if i == len(text1) or j == len(text2):
                return 0

            if text1[i] == text2[j]:
                return 1 + dfs(i + 1, j + 1)

            return max(
                dfs(i + 1, j),
                dfs(i, j + 1)
            )

        return dfs(0, 0)
```

`@cache` 会根据函数参数自动保存返回值。再次以相同的 `(i, j)` 调用 `dfs` 时，会直接返回缓存结果。

## 3. 二维动态规划（自底向上）

### 思路

递归和记忆化搜索都是从 `dfs(0, 0)` 出发，不断向后寻找答案。

也可以反过来，从字符串末尾开始构造答案。

定义：

```
dp[i][j] = text1[i:] 和 text2[j:] 的最长公共子序列长度
```

状态转移为：

```
如果 text1[i] == text2[j]：

dp[i][j] = 1 + dp[i+1][j+1]

否则：

dp[i][j] = max(dp[i+1][j], dp[i][j+1])
```

由于 `dp[i][j]` 依赖右侧、下方和右下方的状态，因此必须从右下角向左上角填表。

### 为什么数组大小是 `(m+1) × (n+1)`

额外的一行和一列表示空字符串的情况：

```
dp[m][j] = 0
dp[i][n] = 0
```

如果其中一个字符串为空，那么最长公共子序列长度一定是 `0`。

### 算法步骤

1. 创建大小为 `(m+1) × (n+1)` 的二维数组，并初始化为 `0`。
2. 让 `i` 从 `m-1` 递减到 `0`。
3. 让 `j` 从 `n-1` 递减到 `0`。
4. 根据两个字符是否相同进行状态转移。
5. 返回 `dp[0][0]`。

```
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        m, n = len(text1), len(text2)

        # dp[i][j] 表示 text1[i:] 和 text2[j:] 的 LCS 长度
        # 额外的一行和一列表示空字符串
        dp = [[0] * (n + 1) for _ in range(m + 1)]

        # 从右下角向左上角填表
        for i in range(m - 1, -1, -1):
            for j in range(n - 1, -1, -1):
                if text1[i] == text2[j]:
                    # 当前字符相同，同时移动两个索引
                    dp[i][j] = 1 + dp[i + 1][j + 1]
                else:
                    # 跳过 text1[i] 或 text2[j]
                    dp[i][j] = max(
                        dp[i + 1][j],
                        dp[i][j + 1]
                    )

        return dp[0][0]
```

### Python 二维列表说明

下面的写法会创建 `m+1` 个彼此独立的列表：

```
dp = [[0] * (n + 1) for _ in range(m + 1)]
```

不要写成：

```
dp = [[0] * (n + 1)] * (m + 1)
```

后一种写法会让所有行引用同一个列表。修改其中一行时，其他行也会一起改变。

### `range` 说明

```
range(m - 1, -1, -1)
```

三个参数分别是：

```
range(起点, 终点, 步长)
```

终点本身不会被包含，因此这里会依次产生：

```
m-1, m-2, ..., 1, 0
```

### 复杂度分析

- 时间复杂度：`O(m × n)`
- 空间复杂度：`O(m × n)`

二维数组共有 `(m+1) × (n+1)` 个位置，每个位置的计算时间为 `O(1)`。

## 4. 动态规划：两个一维数组

### 思路

在二维动态规划中，`dp[i][j]` 只依赖：

```
dp[i+1][j]     下一行的当前位置
dp[i+1][j+1]   下一行的右侧位置
dp[i][j+1]     当前行的右侧位置
```

因此不需要保存整个二维数组，只需要保存：

- `prev`：下一行；
- `curr`：当前正在计算的行。

为了让空间复杂度尽可能小，可以让较短的字符串作为第二个字符串，因为一维数组的长度由 `text2` 决定。

### 算法步骤

1. 保证 `text2` 是较短的字符串。
2. 创建两个长度为 `n+1` 的数组 `prev` 和 `curr`。
3. 从后向前遍历 `text1`。
4. 对于每一行，从后向前遍历 `text2` 并计算 `curr[j]`。
5. 当前行计算完成后，交换 `prev` 和 `curr`。
6. 返回 `prev[0]`。

```
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        # 保证 text2 是较短的字符串，以减少一维数组长度
        if len(text1) < len(text2):
            text1, text2 = text2, text1

        n = len(text2)

        # prev 表示二维 DP 中的下一行
        # curr 表示二维 DP 中的当前行
        prev = [0] * (n + 1)
        curr = [0] * (n + 1)

        for i in range(len(text1) - 1, -1, -1):
            for j in range(n - 1, -1, -1):
                if text1[i] == text2[j]:
                    # 对应二维 DP 中的：
                    # dp[i][j] = 1 + dp[i+1][j+1]
                    curr[j] = 1 + prev[j + 1]
                else:
                    # curr[j+1] 对应 dp[i][j+1]
                    # prev[j] 对应 dp[i+1][j]
                    curr[j] = max(curr[j + 1], prev[j])

            # 当前行变成下一轮的“下一行”
            prev, curr = curr, prev

        return prev[0]
```

### Python 交换变量说明

Python 可以在一行中交换两个变量：

```
prev, curr = curr, prev
```

其效果相当于交换两个变量所引用的列表，不需要手动创建临时变量。

### 复杂度分析

- 时间复杂度：`O(m × n)`
- 空间复杂度：`O(min(m, n))`

虽然减少了空间，但它只能计算 LCS 的长度。如果需要恢复出具体的最长公共子序列，通常保留完整的二维 DP 表会更加方便。

## 5. 动态规划：单个一维数组

### 思路

两个一维数组还可以进一步压缩为一个数组。

开始计算新的一行之前：

```
dp[j] 表示 dp[i+1][j]
```

从右向左更新时：

```
dp[j+1] 表示已经更新后的 dp[i][j+1]
```

还需要一个变量保存右下角的旧值：

```
dp[i+1][j+1]
```

代码中使用 `diagonal` 保存这个值。相比将它命名为 `prev`，`diagonal` 更能说明它在二维 DP 表中的含义。

### 算法步骤

1. 保证 `text2` 是较短的字符串。
2. 创建长度为 `n+1` 的一维数组 `dp`。
3. 从后向前遍历 `text1`。
4. 每一行开始时，将 `diagonal` 初始化为 `0`。
5. 从后向前遍历 `text2`：
   - 先保存更新前的 `dp[j]`；
   - 根据字符是否相同更新 `dp[j]`；
   - 将旧的 `dp[j]` 保存到 `diagonal`，供下一次迭代使用。
6. 返回 `dp[0]`。

```
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        # 让 text2 成为较短的字符串
        if len(text1) < len(text2):
            text1, text2 = text2, text1

        n = len(text2)
        dp = [0] * (n + 1)

        for i in range(len(text1) - 1, -1, -1):
            # 对应二维 DP 中的 dp[i+1][j+1]
            diagonal = 0

            for j in range(n - 1, -1, -1):
                # 保存更新前的 dp[j]，即 dp[i+1][j]
                old_dp_j = dp[j]

                if text1[i] == text2[j]:
                    # diagonal 是右下角的旧值 dp[i+1][j+1]
                    dp[j] = 1 + diagonal
                else:
                    # dp[j] 尚未更新，表示 dp[i+1][j]
                    # dp[j+1] 已经更新，表示 dp[i][j+1]
                    dp[j] = max(dp[j], dp[j + 1])

                # 对于下一个 j，旧的 dp[j] 会成为其右下角状态
                diagonal = old_dp_j

        return dp[0]
```

### 为什么必须从右向左更新

更新 `dp[j]` 时，需要使用本行已经计算好的：

```
dp[i][j+1]
```

它对应一维数组中的 `dp[j+1]`。

因此，`j+1` 必须先于 `j` 被更新，也就是需要从右向左遍历。

如果从左向右更新，数组中的值可能来自错误的行，破坏状态转移关系。

### 复杂度分析

- 时间复杂度：`O(m × n)`
- 空间复杂度：`O(min(m, n))`

这已经是仅计算 LCS 长度时常用的最优空间复杂度。

------

## 方法对比

| 方法         | 时间复杂度   | 空间复杂度    | 特点                               |
| ------------ | ------------ | ------------- | ---------------------------------- |
| 普通递归     | `O(2^(m+n))` | `O(m+n)`      | 容易理解，但存在大量重复计算       |
| 记忆化搜索   | `O(mn)`      | `O(mn)`       | 递归结构清晰，但可能受递归深度限制 |
| 二维动态规划 | `O(mn)`      | `O(mn)`       | 最直观，方便恢复具体的 LCS         |
| 两个一维数组 | `O(mn)`      | `O(min(m,n))` | 空间更小，逻辑仍较清晰             |
| 单个一维数组 | `O(mn)`      | `O(min(m,n))` | 空间最优，但状态含义更容易混淆     |

面试中通常建议优先写出二维动态规划，因为它最容易解释和验证。如果面试官继续询问空间优化，再将二维数组压缩为一维数组。

## 常见错误

### 1. 混淆子序列与子串

子序列中的字符不需要连续，只需要保持相对顺序。

例如：

```
"ace" 是 "abcde" 的子序列，但不是子串。
```

当字符不相同时，LCS 不会将答案直接清零，而是尝试跳过其中一个字符：

```
max(dp[i + 1][j], dp[i][j + 1])
```

如果在字符不匹配时将长度重置为 `0`，求出的通常是最长公共子串，而不是最长公共子序列。

### 2. DP 数组缺少额外的一行和一列

二维 DP 数组应当创建为：

```
(m + 1) × (n + 1)
```

这样才能安全访问：

```
dp[i + 1][j]
dp[i][j + 1]
dp[i + 1][j + 1]
```

额外的一行和一列同时代表空字符串对应的边界状态。

### 3. 自底向上的遍历方向错误

由于 `dp[i][j]` 依赖：

```
dp[i+1][j]
dp[i][j+1]
dp[i+1][j+1]
```

所以采用当前状态定义时，必须从字符串末尾向开头遍历。

### 4. 一维 DP 中覆盖了仍然需要的值

单数组版本会原地修改 `dp[j]`。在修改之前，必须先保存它的旧值：

```
old_dp_j = dp[j]
```

这个旧值将在下一次循环中作为右下角状态使用。

### 5. 尝试恢复具体序列却只保存一维数组

一维 DP 足以计算 LCS 的长度，但无法直接、方便地恢复出具体的最长公共子序列。

如果题目要求返回具体序列，更适合使用完整的二维 DP 表，然后从 `dp[0][0]` 开始沿状态转移路径回溯。
