# 子集（Subsets）

给定一个由**互不相同的整数**组成的数组 `nums`，返回该数组所有可能的子集（即幂集）。

结果中不能包含重复的子集，可以按**任意顺序**返回。

例如：

```
输入：nums = [1, 2, 3]

输出：
[
    [],
    [1],
    [2],
    [3],
    [1, 2],
    [1, 3],
    [2, 3],
    [1, 2, 3]
]
```

如果数组长度为 `n`，那么它一共有：

\[ 2^n \]

个不同的子集。因为对于每个元素，都有“选择”和“不选择”两种可能。

------

## 解法一：回溯法

### 思路

从左到右处理数组中的每个元素。对于每个元素，我们都需要做出两个选择：

1. 将当前元素加入子集；
2. 不将当前元素加入子集。

这两个选择自然形成了一棵二叉决策树：

```
                    []
              /             \
          选择 1            不选 1
           [1]                []
         /     \            /     \
      选 2    不选 2      选 2    不选 2
```

当递归处理完所有元素时，当前构造的列表就是一个完整的子集，将其保存到结果中即可。

回溯的关键是：

```
subset.append(nums[i])
dfs(i + 1)
subset.pop()
```

`pop()` 会撤销刚才的选择，使程序能够继续探索“不选择当前元素”的分支。

### 算法步骤

1. 使用 `res` 保存所有子集。
2. 使用 `subset` 保存当前正在构造的子集。
3. 定义递归函数 `dfs(i)`，表示处理下标 `i` 及其之后的元素。
4. 对于 `nums[i]`：
   - 先选择它，递归处理下一个元素；
   - 撤销选择；
   - 再跳过它，递归处理下一个元素。
5. 当 `i == len(nums)` 时，将当前子集的副本加入结果。

### 代码

```
from typing import List


class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        # 保存最终生成的所有子集
        res: List[List[int]] = []

        # 当前正在构造的子集
        subset: List[int] = []

        def dfs(i: int) -> None:
            # 所有元素都已经完成选择
            if i == len(nums):
                # 必须保存副本，不能直接保存 subset 本身
                res.append(subset.copy())
                return

            # 选择一：将 nums[i] 加入当前子集
            subset.append(nums[i])
            dfs(i + 1)

            # 回溯：撤销刚才的选择
            subset.pop()

            # 选择二：不将 nums[i] 加入当前子集
            dfs(i + 1)

        dfs(0)
        return res
```

### 复杂度分析

设数组长度为 `n`。

- 时间复杂度：\(O(n \cdot 2^n)\)
  - 一共有 \(2^n\) 个子集；
  - 保存每个子集的副本最多需要 \(O(n)\) 时间。
- 辅助空间复杂度：\(O(n)\)
  - 递归栈深度最大为 `n`；
  - 当前子集最多包含 `n` 个元素。
- 包含返回结果的总空间复杂度：\(O(n \cdot 2^n)\)
  - 所有子集总共需要存储约 \(n \cdot 2^{n-1}\) 个元素。

### 方法总结

这是最符合“选择或不选择”思维的解法，也最容易扩展到其他组合、排列和搜索问题。面试中通常优先推荐这种方法。

------

## 解法二：迭代法

### 思路

最开始只有一个子集，即空集：

```
[[]]
```

对于数组中的每个元素，将它添加到当前已有的每个子集中，从而生成一批新的子集。

以 `nums = [1, 2, 3]` 为例：

```
开始：
[[]]

处理 1：
[[], [1]]

处理 2：
[[], [1], [2], [1, 2]]

处理 3：
[[], [1], [2], [1, 2],
 [3], [1, 3], [2, 3], [1, 2, 3]]
```

每处理一个元素，子集数量都会翻倍。

### 算法步骤

1. 初始化 `res = [[]]`，因为空集一定是一个子集。
2. 遍历数组中的每个元素 `num`。
3. 将 `num` 添加到当前所有子集中，得到新的子集。
4. 把这些新子集追加到结果中。
5. 返回结果。

### 代码

```
from typing import List


class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        # 幂集一定包含空集
        res: List[List[int]] = [[]]

        for num in nums:
            # 对当前已有的每个子集，都生成一个包含 num 的新子集
            new_subsets = [subset + [num] for subset in res]

            # 将新生成的子集加入结果
            res.extend(new_subsets)

        return res
```

也可以简写为：

```
from typing import List


class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        res = [[]]

        for num in nums:
            res += [subset + [num] for subset in res]

        return res
```

这里的：

```
subset + [num]
```

不会修改原来的 `subset`，而是返回一个新的列表。

### 复杂度分析

- 时间复杂度：\(O(n \cdot 2^n)\)
- 额外辅助空间：最坏为 \(O(n \cdot 2^n)\)
  - `new_subsets` 会暂时保存当前轮生成的所有新子集。
- 包含返回结果的总空间复杂度：\(O(n \cdot 2^n)\)

### 方法总结

迭代法不需要递归，代码简洁直观。它的核心思想是：

> 每加入一个新元素，就复制现有的所有子集，并在副本中加入该元素。

## 解法三：位运算法

### 思路

对于长度为 `n` 的数组，每个元素都只有两种状态：

- `0`：不选择；
- `1`：选择。

因此，可以用一个长度为 `n` 的二进制数表示一个子集。

例如，对于：

```
nums = ["a", "b", "c"]
```

可以约定二进制数从低位到高位依次对应 `a`、`b`、`c`：

```
000 → []
001 → [a]
010 → [b]
011 → [a, b]
100 → [c]
101 → [a, c]
110 → [b, c]
111 → [a, b, c]
```

从 `0` 到 `2^n - 1` 一共有 `2^n` 个整数，恰好可以表示所有子集。

对于每个位掩码 `mask`，检查它的第 `j` 位：

```
mask & (1 << j)
```

如果结果不为 `0`，说明第 `j` 位是 `1`，需要将 `nums[j]` 加入当前子集。

### 算法步骤

1. 令 `n = len(nums)`。
2. 遍历从 `0` 到 `2^n - 1` 的所有整数，将其作为位掩码。
3. 对每个位掩码，检查从 `0` 到 `n - 1` 的每一位。
4. 如果第 `j` 位为 `1`，就选择 `nums[j]`。
5. 将构造出的子集加入结果。

### 代码

```
from typing import List


class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        n = len(nums)
        res: List[List[int]] = []

        # 1 << n 等价于 2 ** n
        for mask in range(1 << n):
            subset: List[int] = []

            for j in range(n):
                # 检查 mask 的第 j 位是否为 1
                if mask & (1 << j):
                    subset.append(nums[j])

            res.append(subset)

        return res
```

也可以使用列表推导式简写：

```
from typing import List


class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        n = len(nums)
        res = []

        for mask in range(1 << n):
            subset = [
                nums[j]
                for j in range(n)
                if mask & (1 << j)
            ]
            res.append(subset)

        return res
```

### 位运算说明

#### `1 << n`

将数字 `1` 向左移动 `n` 位，等价于：

\[ 2^n \]

例如：

```
1 << 3  # 8，二进制为 1000
```

#### `1 << j`

生成一个只有第 `j` 位为 `1` 的二进制数。

例如：

```
1 << 2  # 4，二进制为 0100
```

#### `mask & (1 << j)`

利用按位与运算检查 `mask` 的第 `j` 位是否为 `1`。

```
mask = 5       # 二进制 0101
1 << 2         # 二进制 0100

mask & (1 << 2)  # 结果为 0100，不为 0
```

因此，`mask` 的第 `2` 位是 `1`。

### 复杂度分析

- 时间复杂度：\(O(n \cdot 2^n)\)
  - 一共有 \(2^n\) 个位掩码；
  - 每个位掩码都要检查 `n` 个二进制位。
- 辅助空间复杂度：\(O(n)\)
  - 不计算返回结果时，当前子集最多保存 `n` 个元素。
- 包含返回结果的总空间复杂度：\(O(n \cdot 2^n)\)

### 方法总结

位运算法将“选择或不选择”直接编码为二进制位，适合以下场景：

- 需要枚举所有状态；
- 需要通过整数高效地保存集合状态；
- 后续问题涉及状态压缩动态规划。

不过与回溯法相比，它的可读性稍弱。

------

## 三种方法对比

| 方法     | 核心思想                     | 时间复杂度  | 辅助空间    | 特点                         |
| -------- | ---------------------------- | ----------- | ----------- | ---------------------------- |
| 回溯法   | 每个元素选择或不选择         | \(O(n2^n)\) | \(O(n)\)    | 最符合递归搜索思维，容易扩展 |
| 迭代法   | 在已有子集基础上生成新子集   | \(O(n2^n)\) | \(O(n2^n)\) | 简洁直观，不使用递归         |
| 位运算法 | 用二进制位表示元素是否被选择 | \(O(n2^n)\) | \(O(n)\)    | 适合状态枚举和状态压缩       |

这里的辅助空间均不包含最终返回的结果。无论采用哪种方法，返回结果本身都需要 \(O(n2^n)\) 的空间。

## 常见错误

### 1. 回溯时没有保存当前子集的副本

下面的写法是错误的：

```
res.append(subset)
```

Python 列表是可变对象。上面的代码保存的是同一个列表对象的引用，之后执行 `append()` 或 `pop()` 时，已经加入结果中的内容也会随之改变。

正确写法：

```
res.append(subset.copy())
```

也可以写成：

```
res.append(subset[:])
```

或者：

```
res.append(list(subset))
```

------

### 2. 回溯之后忘记撤销选择

错误示例：

```
subset.append(nums[i])
dfs(i + 1)

# 忘记执行 subset.pop()
dfs(i + 1)
```

这样第二个递归分支中仍然包含当前元素，因此无法正确表示“不选择当前元素”。

正确写法：

```
subset.append(nums[i])
dfs(i + 1)

subset.pop()  # 撤销选择
dfs(i + 1)
```

------

### 3. 忘记空集

空集 `[]` 永远属于幂集。

迭代法必须从下面的状态开始：

```
res = [[]]
```

不能写成：

```
res = []
```

对于空数组：

```
nums = []
```

正确结果应该是：

```
[[]]
```

注意，`[]` 表示“没有任何子集”，而 `[[]]` 表示“存在一个子集，这个子集是空集”。

------

### 4. 混淆递归下标的含义

在本文的“选择或不选择”写法中，`dfs(i)` 表示正在决定是否选择 `nums[i]`，因此两个递归分支都必须进入：

```
dfs(i + 1)
```

如果写成 `dfs(i)`，就会重复处理同一个元素，甚至造成无限递归。

另一种常见的回溯模板是通过 `for` 循环枚举下一个元素：

```
def dfs(start: int) -> None:
    res.append(subset.copy())

    for j in range(start, len(nums)):
        subset.append(nums[j])
        dfs(j + 1)
        subset.pop()
```

这里应该从 `start` 开始枚举，而递归时传入 `j + 1`。两种模板的下标含义不同，不要混用。

------

### 5. 位掩码的位与数组下标没有对应好

本文代码约定：

```
第 j 个二进制位 ↔ nums[j]
```

因此检查条件应为：

```
mask & (1 << j)
```

只要整个算法始终使用同一种对应关系，最终子集的顺序并不影响答案。

------

### 6. 位移运算的整数范围

在 C++ 或 Java 等使用固定位数整数的语言中，`1 << n` 可能发生溢出，或者因为位移位数过大而产生非预期结果。必要时应使用更大的整数类型，例如：

```
1LL << n
```

Python 的整数支持任意精度，因此 `1 << n` 不会发生传统意义上的整数溢出。不过，子集数量本身为 \(2^n\)，当 `n` 较大时，时间和内存会先变得不可接受。
