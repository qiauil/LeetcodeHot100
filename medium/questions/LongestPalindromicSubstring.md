# 最长回文子串（Longest Palindromic Substring）

## 题目描述

给定一个字符串 `s`，返回 `s` 中最长的**回文子串**。

**回文串（Palindrome）**是指正着读和反着读完全相同的字符串。

如果存在多个长度相同的最长回文子串，返回其中任意一个即可。

### 约束

- `1 <= s.length <= 1000`
- `s` 只包含数字和英文字母

---

## 一、暴力枚举

### 核心思路

最直接的方法是：

1. 枚举字符串中的每一个子串。
2. 对每个子串判断它是否为回文串。
3. 如果是回文串，并且比当前记录的答案更长，就更新答案。

对于每一对下标 `(i, j)`，把 `s[i:j+1]` 看作候选子串，然后使用两个指针：

- `l` 从左端开始；
- `r` 从右端开始；
- 如果 `s[l] == s[r]`，则继续向中间移动；
- 如果最终 `l >= r`，说明该子串是回文串。

这种方法非常直观，但会重复检查大量相同的字符，因此效率较低。

### 算法步骤

1. 初始化最长回文子串 `res = ""`，最长长度 `resLen = 0`。
2. 枚举起点 `i`。
3. 枚举终点 `j`，其中 `j >= i`。
4. 使用双指针判断 `s[i:j+1]` 是否为回文串。
5. 如果是回文串，并且长度大于当前最长长度，则更新答案。
6. 返回最终结果。

### Python 实现

```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        res = ""
        resLen = 0

        # 枚举子串起点
        for i in range(len(s)):
            # 枚举子串终点
            for j in range(i, len(s)):
                l, r = i, j

                # 从两端向中间判断是否为回文串
                while l < r and s[l] == s[r]:
                    l += 1
                    r -= 1

                # 如果 l >= r，说明整个子串是回文串
                currLen = j - i + 1
                if l >= r and currLen > resLen:
                    res = s[i:j + 1]
                    resLen = currLen

        return res
```

### 复杂度分析

设字符串长度为 `n`。

- **时间复杂度：`O(n^3)`**
  - 一共有 `O(n^2)` 个子串；
  - 判断每个子串是否为回文串最坏需要 `O(n)` 时间。

- **额外空间复杂度：`O(1)`**
  - 如果不计算最终返回的字符串，只使用了常数个变量。
  - Python 中切片 `s[i:j+1]` 会创建新字符串，因此保存答案本身最多需要 `O(n)` 空间。

### 算法总结

暴力法适合理解题意，但通常不是面试中最终期望的解法。

对于本题 `n <= 1000`，`O(n^3)` 在最坏情况下可能非常慢，因此应该继续寻找更高效的方法。

---

## 二、动态规划

### 核心思路

暴力法的问题在于：很多子串是否为回文串会被反复检查。

动态规划的想法是把这些结果保存下来。

定义：

```text
dp[i][j] = True
```

表示子串：

```text
s[i : j + 1]
```

是回文串。

对于一个子串 `s[i..j]`，它是回文串需要满足：

```text
s[i] == s[j]
```

并且内部子串：

```text
s[i + 1 .. j - 1]
```

也是回文串。

因此状态转移为：

```text
dp[i][j] =
    s[i] == s[j]
    且
    (j - i <= 2 或 dp[i + 1][j - 1])
```

### 为什么 `j - i <= 2` 可以直接判断？

这里对应长度为 `1`、`2`、`3` 的子串。

#### 长度为 1

例如：

```text
"a"
```

单个字符一定是回文串。

#### 长度为 2

例如：

```text
"aa"
```

只要两端字符相等，就是回文串。

#### 长度为 3

例如：

```text
"aba"
```

只要首尾相同，中间只有一个字符，而单个字符天然是回文串。

因此当：

```python
j - i <= 2
```

时，只需要判断：

```python
s[i] == s[j]
```

即可。

### 为什么 `i` 要从右向左遍历？

状态：

```python
dp[i][j]
```

依赖：

```python
dp[i + 1][j - 1]
```

因此在计算 `dp[i][j]` 之前，需要保证下一行 `dp[i+1][...]` 已经计算完成。

所以 `i` 应从：

```text
n - 1 -> 0
```

倒序遍历。

### 算法步骤

1. 创建 `n × n` 的二维布尔数组 `dp`。
2. `dp[i][j]` 表示 `s[i:j+1]` 是否为回文串。
3. 从右向左枚举 `i`。
4. 从 `i` 开始向右枚举 `j`。
5. 根据状态转移公式判断 `dp[i][j]`。
6. 每发现一个更长的回文串，就更新答案起点和长度。
7. 最后通过字符串切片返回答案。

### Python 实现

```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        n = len(s)

        # 最长回文子串的起始位置和长度
        resIdx = 0
        resLen = 0

        # dp[i][j] 表示 s[i:j+1] 是否为回文串
        dp = [[False] * n for _ in range(n)]

        # i 必须从右向左遍历，
        # 因为 dp[i][j] 依赖 dp[i+1][j-1]
        for i in range(n - 1, -1, -1):
            for j in range(i, n):
                if (
                    s[i] == s[j]
                    and (j - i <= 2 or dp[i + 1][j - 1])
                ):
                    dp[i][j] = True

                    currLen = j - i + 1

                    if currLen > resLen:
                        resIdx = i
                        resLen = currLen

        return s[resIdx:resIdx + resLen]
```

### Python 语法说明：二维列表初始化

下面这种写法：

```python
dp = [[False] * n for _ in range(n)]
```

会创建 `n` 个互相独立的列表，因此适合创建二维数组。

不推荐写成：

```python
dp = [[False] * n] * n
```

因为这种写法实际上会让每一行引用**同一个列表对象**。

例如：

```python
dp = [[False] * 3] * 3
dp[0][0] = True

print(dp)
```

结果会变成：

```python
[
    [True, False, False],
    [True, False, False],
    [True, False, False]
]
```

这通常不是动态规划想要的结果。

### 复杂度分析

- **时间复杂度：`O(n^2)`**
  - 一共有约 `n² / 2` 个状态需要计算。
  - 每个状态的转移只需要 `O(1)` 时间。

- **空间复杂度：`O(n^2)`**
  - 需要一个 `n × n` 的 DP 表。

### 算法总结

动态规划把“重复判断内部子串是否为回文”的过程缓存下来，把时间复杂度从：

```text
O(n^3)
```

降低到：

```text
O(n^2)
```

代价是需要：

```text
O(n^2)
```

额外空间。

对于 `n = 1000`，这通常是可以接受的，但本题还存在只需 `O(1)` 额外空间的 `O(n^2)` 解法。

## 三、中心扩展法（Two Pointers / Expand Around Center）

### 核心思路

回文串具有一个非常重要的性质：

> 回文串一定围绕某个“中心”左右对称。

例如：

```text
racecar
   ^
```

这是奇数长度回文串，中间字符 `e` 是中心。

而：

```text
abba
 ^^
```

这是偶数长度回文串，中心位于两个 `b` 之间。

因此，每一个回文串的中心只可能有两种形式：

1. **奇数长度回文串**
   - 中心是某一个字符；
   - 初始指针为 `(i, i)`。

2. **偶数长度回文串**
   - 中心在两个字符之间；
   - 初始指针为 `(i, i + 1)`。

我们只需要枚举每个可能的中心，然后不断向左右扩展。

只要：

```python
s[l] == s[r]
```

就说明当前区间仍然是回文串。

### 算法步骤

对于字符串中的每个位置 `i`：

1. 以 `(i, i)` 为中心，寻找最长奇数长度回文串。
2. 以 `(i, i + 1)` 为中心，寻找最长偶数长度回文串。
3. 每次成功扩展后，检查当前回文串是否比历史答案更长。
4. 更新最长回文子串的起点和长度。
5. 返回结果。

### Python 实现

```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        resIdx = 0
        resLen = 0
        n = len(s)

        for i in range(n):
            # -----------------------
            # 情况 1：奇数长度回文串
            # 中心为 s[i]
            # -----------------------
            l, r = i, i

            while l >= 0 and r < n and s[l] == s[r]:
                currLen = r - l + 1

                if currLen > resLen:
                    resIdx = l
                    resLen = currLen

                # 继续向两侧扩展
                l -= 1
                r += 1

            # -----------------------
            # 情况 2：偶数长度回文串
            # 中心位于 i 和 i+1 之间
            # -----------------------
            l, r = i, i + 1

            while l >= 0 and r < n and s[l] == s[r]:
                currLen = r - l + 1

                if currLen > resLen:
                    resIdx = l
                    resLen = currLen

                l -= 1
                r += 1

        return s[resIdx:resIdx + resLen]
```

### 为什么这种方法是 `O(n^2)`？

字符串中大约有：

```text
2n - 1
```

个可能的回文中心：

- `n` 个字符中心；
- `n - 1` 个字符间隙中心。

对于每个中心，最坏情况下可能扩展 `O(n)` 次。

因此总时间复杂度为：

```text
O(n^2)
```

### 复杂度分析

- **时间复杂度：`O(n^2)`**
- **额外空间复杂度：`O(1)`**
- Python 返回切片产生的输出字符串最多占用 `O(n)` 空间。

### 为什么这是本题非常推荐的面试解法？

它同时具有：

- 思路直观；
- 代码短；
- 不需要二维 DP 表；
- `O(n^2)` 时间；
- `O(1)` 额外空间。

对于本题：

```text
n <= 1000
```

中心扩展法通常已经足够高效，而且比 Manacher 算法更容易在面试中正确写出来和解释清楚。

**如果面试官没有明确要求线性时间，这通常是最值得优先掌握的解法。**

## 四、Manacher 算法

### 核心思路

Manacher 算法可以在线性时间：

```text
O(n)
```

内找到最长回文子串。

它主要解决中心扩展法中的一个问题：

> 不同中心在扩展时会重复比较很多已经知道的信息。

Manacher 算法利用回文串的**镜像对称性**，复用之前计算过的结果，从而减少重复比较。

---

### 1. 统一奇数和偶数长度回文串

原字符串中同时存在两类中心：

```text
aba
```

中心是 `b`。

以及：

```text
abba
```

中心在两个 `b` 之间。

为了统一处理，可以在每个字符之间插入特殊字符 `#`。

例如：

```text
abba
```

转换为：

```text
#a#b#b#a#
```

此时所有回文串都可以看成“奇数长度”的回文串。

例如原字符串中的：

```text
abba
```

对应转换后：

```text
#a#b#b#a#
```

其中心就是中间的 `#`。

---

### 2. `p[i]` 的含义

定义：

```python
p[i]
```

表示在转换后的字符串中，以 `i` 为中心的最长回文半径。

例如：

```text
t = # a # b # a #
        ↑
```

如果某个中心左右可以扩展 3 个字符，那么：

```python
p[i] = 3
```

---

### 3. 利用镜像位置

假设当前已经知道一个回文区间：

```text
[l, r]
```

并且当前下标 `i` 位于区间内部：

```text
i < r
```

由于整个区间关于中心对称，我们可以找到 `i` 的镜像位置：

```text
mirror = l + r - i
```

于是可以利用：

```python
p[mirror]
```

来初始化：

```python
p[i]
```

而不是每次都从 `0` 开始扩展。

但由于 `i` 的回文范围不能直接越过当前已知右边界 `r`，所以：

```python
p[i] = min(r - i, p[mirror])
```

之后再继续尝试向外扩展。

---

### 4. 更新最右回文区间

如果以 `i` 为中心的回文串扩展到了更远的位置：

```python
i + p[i] > r
```

那么更新：

```python
l = i - p[i]
r = i + p[i]
```

这样后续位置就可以继续使用这个更大的回文区间。

---

### Python 实现

```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        def manacher(s: str) -> list[int]:
            # 在字符之间以及首尾插入 '#'
            # 例如 "abba" -> "#a#b#b#a#"
            t = "#" + "#".join(s) + "#"

            n = len(t)

            # p[i] 表示以 i 为中心的最大回文半径
            p = [0] * n

            # 当前已知的、右边界最远的回文区间 [l, r]
            l, r = 0, 0

            for i in range(n):
                if i < r:
                    # i 关于当前回文中心的镜像位置
                    mirror = l + r - i

                    # 先利用镜像位置已经计算出的结果
                    p[i] = min(r - i, p[mirror])

                # 尝试继续向两侧扩展
                while (
                    i - p[i] - 1 >= 0
                    and i + p[i] + 1 < n
                    and t[i - p[i] - 1] == t[i + p[i] + 1]
                ):
                    p[i] += 1

                # 如果当前回文串突破了原来的右边界，
                # 就更新当前最右回文区间
                if i + p[i] > r:
                    l = i - p[i]
                    r = i + p[i]

            return p

        p = manacher(s)

        # 找到最大回文半径以及对应中心
        resLen, centerIdx = max(
            (radius, i)
            for i, radius in enumerate(p)
        )

        # 将转换后字符串中的位置映射回原字符串
        resIdx = (centerIdx - resLen) // 2

        return s[resIdx:resIdx + resLen]
```

### Python 函数说明：`enumerate`

代码：

```python
enumerate(p)
```

会同时返回：

```text
下标, 元素
```

例如：

```python
nums = [10, 20, 30]

for i, value in enumerate(nums):
    print(i, value)
```

输出：

```text
0 10
1 20
2 30
```

因此：

```python
(radius, i)
for i, radius in enumerate(p)
```

会生成：

```text
(回文半径, 中心下标)
```

然后：

```python
max(...)
```

首先按照回文半径比较。

如果存在多个相同的最大半径，Python tuple 会继续比较第二个元素，也就是中心下标。

本题允许返回任意一个最长回文子串，因此这种写法没有问题。

---

### 为什么原字符串中的答案长度正好等于 `resLen`？

转换后：

```text
abba
```

变成：

```text
#a#b#b#a#
```

虽然转换后的回文半径是在包含 `#` 的字符串中计算的，但由于字符和 `#` 交替出现，最大半径 `p[i]` 数值恰好等于原字符串中对应回文串的字符长度。

因此可以直接使用：

```python
resLen
```

作为原字符串切片长度。

起始位置则通过：

```python
(centerIdx - resLen) // 2
```

映射回原字符串。

---

### 复杂度分析

- **时间复杂度：`O(n)`**
- **空间复杂度：`O(n)`**
  - 转换后的字符串长度约为 `2n + 1`；
  - `p` 数组也需要线性空间。

### 算法总结

Manacher 算法是这道题理论复杂度最优的经典解法。

但它的缺点也很明显：

- 实现复杂；
- 边界容易写错；
- 镜像关系较难解释；
- 面试中从零实现的出错概率高。

因此建议掌握顺序为：

```text
中心扩展法
    ↓
动态规划
    ↓
Manacher 算法
```

如果面试官明确追问：

> 能否把时间复杂度优化到 `O(n)`？

这时再使用 Manacher 算法通常更合适。

# 常见错误

## 1. 只处理奇数长度回文串

如果只从：

```python
l, r = i, i
```

开始扩展，那么可以找到：

```text
aba
racecar
abcba
```

但无法找到：

```text
aa
abba
baab
```

因为偶数长度回文串的中心位于两个字符之间。

因此中心扩展法必须同时考虑：

```python
(i, i)
```

和：

```python
(i, i + 1)
```

---

## 2. 字符串切片的右边界错误

Python 切片：

```python
s[start:end]
```

包含：

```text
start
```

但**不包含**：

```text
end
```

因此如果回文区间是闭区间：

```text
[l, r]
```

正确切片应该写成：

```python
s[l:r + 1]
```

而不是：

```python
s[l:r]
```

---

## 3. 双指针扩展结束后忘记指针已经越界

假设使用：

```python
while l >= 0 and r < n and s[l] == s[r]:
    l -= 1
    r += 1
```

循环退出时：

```text
l
```

和：

```text
r
```

已经指向真正回文串外面的位置。

因此此时真正的回文边界是：

```text
[l + 1, r - 1]
```

这也是回文题中非常常见的 off-by-one 错误来源。

本文代码通过在每次成功匹配时立即记录：

```python
resIdx = l
resLen = r - l + 1
```

避免了扩展结束后再修正边界。

---

## 4. 单字符输入返回空字符串

对于：

```text
s = "a"
```

答案应该是：

```text
"a"
```

如果答案初始化为空字符串，并且更新条件写得不正确，就可能错误返回：

```text
""
```

中心扩展法中：

```python
l, r = i, i
```

会立即识别单个字符本身就是回文串，因此可以自然处理这种情况。

---

## 5. 动态规划遍历顺序错误

状态：

```python
dp[i][j]
```

依赖：

```python
dp[i + 1][j - 1]
```

因此如果从：

```text
i = 0 -> n - 1
```

向右遍历，可能在读取：

```python
dp[i + 1][j - 1]
```

时，该状态还没有被计算。

所以本文采用：

```python
for i in range(n - 1, -1, -1):
```

从右向左计算。

# 解法对比

| 方法 | 时间复杂度 | 额外空间复杂度 | 面试推荐程度 |
|---|---:|---:|---|
| 暴力枚举 | `O(n^3)` | `O(1)` | 适合理解题目 |
| 动态规划 | `O(n^2)` | `O(n^2)` | 推荐 |
| 中心扩展法 | `O(n^2)` | `O(1)` | **最推荐** |
| Manacher | `O(n)` | `O(n)` | 进阶 / 追求最优 |

# 面试时建议优先掌握的解法

对于这道题，最值得在面试中优先写出的通常是**中心扩展法**。

核心记忆点只有两个：

```python
# 奇数长度
l, r = i, i

# 偶数长度
l, r = i, i + 1
```

然后不断执行：

```python
while l >= 0 and r < n and s[l] == s[r]:
    ...
    l -= 1
    r += 1
```

它实现简单、空间复杂度优秀，并且对于：

```text
n <= 1000
```

完全足够。

如果面试官进一步要求线性时间，再讨论 Manacher 算法。
