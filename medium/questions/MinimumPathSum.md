# 最小路径和（Minimum Path Sum）

给定一个包含非负整数的 `m × n` 网格 `grid`，请找出一条从左上角到右下角的路径，使得路径上所有数字之和最小。

每次只能向右或向下移动一步。

------

## 核心思路

对于任意位置 `(r, c)`，到达右下角的最小路径和为：

\[ f(r,c)=grid[r][c]+\min(f(r+1,c),f(r,c+1)) \]

其中：

- `f(r + 1, c)` 表示向下移动后的最小路径和；
- `f(r, c + 1)` 表示向右移动后的最小路径和；
- 如果某个方向越界，就把该方向的路径和视为无穷大。

这道题的不同解法，本质上都使用了同一个状态转移方程，区别只在于计算顺序和结果的存储方式。

------

## 1. 递归

### 思路

在每个位置，我们分别尝试：

- 向下移动；
- 向右移动。

然后选择两条路径中总和较小的一条。

当到达右下角时，直接返回当前格子的值。如果移动后越界，则返回无穷大，表示这不是一条合法路径。

### 算法步骤

1. 定义 `dfs(r, c)`，表示从 `(r, c)` 到右下角的最小路径和。
2. 如果当前位置是右下角，返回当前格子的值。
3. 如果当前位置越界，返回无穷大。
4. 分别递归计算向下和向右的结果。
5. 返回当前格子的值加上两个结果中的较小值。

```
from typing import List


class Solution:
    def minPathSum(self, grid: List[List[int]]) -> int:
        rows, cols = len(grid), len(grid[0])

        def dfs(r: int, c: int) -> int:
            # 越界，表示这条路径不合法
            if r == rows or c == cols:
                return float("inf")

            # 到达右下角
            if r == rows - 1 and c == cols - 1:
                return grid[r][c]

            # 尝试向下和向右移动，选择路径和较小的方向
            move_down = dfs(r + 1, c)
            move_right = dfs(r, c + 1)

            return grid[r][c] + min(move_down, move_right)

        return dfs(0, 0)
```

### 复杂度分析

- 时间复杂度：指数级，可写作 \(O(2^{m+n})\)
- 空间复杂度：\(O(m+n)\)

递归树的深度最多为 `m + n - 1`，因此递归调用栈需要 \(O(m+n)\) 的空间。

该方法会反复计算相同的状态。例如，`dfs(0, 1)` 和 `dfs(1, 0)` 都可能继续计算 `dfs(1, 1)`，因此效率很低，通常只能用于帮助理解状态转移。

------

## 2. 自顶向下动态规划：记忆化搜索

### 思路

普通递归中存在大量重复计算。我们可以使用二维数组保存每个位置已经计算出的结果。

当再次访问同一个位置时，直接返回之前保存的结果，不再继续递归。这样，每个格子最多只会被真正计算一次。

### 算法步骤

1. 创建一个 `m × n` 的二维数组 `dp`，初始值全部为 `-1`。
2. `dp[r][c]` 表示从 `(r, c)` 到右下角的最小路径和。
3. 如果 `dp[r][c] != -1`，说明该状态已经计算过，直接返回。
4. 否则，使用状态转移方程计算并保存结果。
5. 最终返回 `dfs(0, 0)`。

```
from typing import List


class Solution:
    def minPathSum(self, grid: List[List[int]]) -> int:
        rows, cols = len(grid), len(grid[0])

        # -1 表示该状态尚未计算
        # 因为题目中的数字都是非负数，所以合法路径和不会是 -1
        dp = [[-1] * cols for _ in range(rows)]

        def dfs(r: int, c: int) -> int:
            # 越界路径无效
            if r == rows or c == cols:
                return float("inf")

            # 到达终点
            if r == rows - 1 and c == cols - 1:
                return grid[r][c]

            # 如果已经计算过，直接返回缓存结果
            if dp[r][c] != -1:
                return dp[r][c]

            move_down = dfs(r + 1, c)
            move_right = dfs(r, c + 1)

            # 保存当前状态的答案
            dp[r][c] = grid[r][c] + min(move_down, move_right)
            return dp[r][c]

        return dfs(0, 0)
```

### 复杂度分析

- 时间复杂度：\(O(mn)\)
- 空间复杂度：\(O(mn)\)

每个格子只会被计算一次。二维缓存需要 \(O(mn)\) 空间，递归调用栈还需要 \(O(m+n)\) 空间，因此整体空间复杂度仍为 \(O(mn)\)。

## 3. 自底向上动态规划

### 思路

我们不一定要从左上角递归到右下角，也可以从右下角开始，反向计算每个格子的最小路径和。

定义：

\[ dp[r][c] \]

表示从 `(r, c)` 到右下角的最小路径和。

因为当前位置只能向下或向右移动，所以：

\[ dp[r][c] = grid[r][c] + \min(dp[r+1][c],dp[r][c+1]) \]

为了统一处理边界，可以额外添加一行和一列，并将其初始化为无穷大。

### 算法步骤

1. 创建大小为 `(rows + 1) × (cols + 1)` 的二维数组，并初始化为无穷大。
2. 将终点右侧的虚拟位置 `dp[rows - 1][cols]` 设置为 `0`。
3. 从右下角开始，按照从下到上、从右到左的顺序遍历。
4. 根据状态转移方程计算每个格子的结果。
5. 返回 `dp[0][0]`。

```
from typing import List


class Solution:
    def minPathSum(self, grid: List[List[int]]) -> int:
        rows, cols = len(grid), len(grid[0])

        # 额外增加一行和一列，用于统一处理边界
        dp = [
            [float("inf")] * (cols + 1)
            for _ in range(rows + 1)
        ]

        # 将终点右侧的虚拟位置设为 0
        # 这样右下角就能得到：
        # grid[rows - 1][cols - 1] + min(inf, 0)
        dp[rows - 1][cols] = 0

        # 从右下角向左上角计算
        for r in range(rows - 1, -1, -1):
            for c in range(cols - 1, -1, -1):
                dp[r][c] = grid[r][c] + min(
                    dp[r + 1][c],  # 向下
                    dp[r][c + 1],  # 向右
                )

        return dp[0][0]
```

也可以把 `dp[rows][cols - 1]` 设置为 `0`。这两种写法的作用相同：给右下角提供一个唯一的合法虚拟入口。

### 复杂度分析

- 时间复杂度：\(O(mn)\)
- 空间复杂度：\(O(mn)\)

每个格子只处理一次。

## 4. 空间优化动态规划

### 思路

在二维动态规划中，计算 `dp[r][c]` 时只需要：

- 下方的值 `dp[r + 1][c]`；
- 右侧的值 `dp[r][c + 1]`。

因此不需要保存整个二维数组，只需要一个长度为 `cols + 1` 的一维数组。

在处理当前格子之前：

- `dp[c]` 保存下方格子的结果；
- `dp[c + 1]` 保存右侧格子的结果。

更新之后：

- `dp[c]` 保存当前格子的结果。

### 算法步骤

1. 创建长度为 `cols + 1` 的一维数组，初始值全部为无穷大。
2. 将 `dp[cols - 1]` 设置为 `0`。
3. 按照从下到上、从右到左的顺序遍历网格。
4. 使用下面的公式更新：

\[ dp[c]=grid[r][c]+\min(dp[c],dp[c+1]) \]

1. 返回 `dp[0]`。

```
from typing import List


class Solution:
    def minPathSum(self, grid: List[List[int]]) -> int:
        rows, cols = len(grid), len(grid[0])

        # dp[c] 在更新前表示下方格子的结果
        # dp[c + 1] 表示右侧格子的结果
        dp = [float("inf")] * (cols + 1)

        # 为右下角设置虚拟入口
        dp[cols - 1] = 0

        for r in range(rows - 1, -1, -1):
            # 必须从右向左遍历
            for c in range(cols - 1, -1, -1):
                dp[c] = grid[r][c] + min(
                    dp[c],      # 来自下方
                    dp[c + 1],  # 来自右侧
                )

        return dp[0]
```

### 复杂度分析

- 时间复杂度：\(O(mn)\)
- 空间复杂度：\(O(n)\)

这是几种解法中空间效率最高的一种。

如果列数远大于行数，还可以重新设计遍历方向，使一维数组的长度等于较小的维度，从而将空间复杂度进一步表述为：

\[ O(\min(m,n)) \]

## Python 相关说明

### `List[List[int]]`

```
from typing import List
```

`List[List[int]]` 是类型标注，表示“元素为整数列表的列表”，也就是一个二维整数数组。

例如：

```
grid: List[List[int]] = [
    [1, 3, 1],
    [1, 5, 1],
    [4, 2, 1],
]
```

在较新的 Python 版本中，也可以写成：

```
grid: list[list[int]]
```

类型标注主要用于提高代码可读性和帮助静态检查，本身不会改变程序的运行逻辑。

### `float("inf")`

```
float("inf")
```

表示正无穷大。任何正常的有限路径和都会小于它，因此很适合用来表示无效路径或尚不可达的状态。

例如：

```
min(10, float("inf"))  # 结果为 10
```

### `range(start, stop, step)`

代码中的：

```
range(rows - 1, -1, -1)
```

表示从 `rows - 1` 开始，每次减 `1`，一直遍历到 `0`。其中停止位置 `-1` 不会被包含。

例如：

```
list(range(3, -1, -1))
# [3, 2, 1, 0]
```

### 二维数组的正确初始化方式

推荐写法：

```
dp = [[-1] * cols for _ in range(rows)]
```

不要写成：

```
dp = [[-1] * cols] * rows
```

后一种写法会让每一行引用同一个列表，修改其中一行时，其他行也会一起改变。

## 常见错误

### 1. 边界初始化为 `0`

在自底向上的动态规划中，如果把额外的一行和一列全部初始化为 `0`，算法可能会把越界方向当成更短的路径。

错误示例：

```
dp = [[0] * (cols + 1) for _ in range(rows + 1)]
```

正确做法是把无效边界初始化为无穷大，只留下一个值为 `0` 的虚拟入口：

```
dp = [
    [float("inf")] * (cols + 1)
    for _ in range(rows + 1)
]
dp[rows - 1][cols] = 0
```

### 2. 一维动态规划的遍历方向错误

在当前状态依赖右侧状态时，必须从右向左遍历：

```
for c in range(cols - 1, -1, -1):
```

如果从左向右遍历，某些仍然需要使用的旧状态可能被提前覆盖，导致计算错误。

### 3. 固定长度整数溢出

在 Java、C++ 等语言中，如果使用最大整数表示无穷大，再进行加法：

```
grid[r][c] + Integer.MAX_VALUE
```

可能发生整数溢出，得到负数或其他错误结果。

可以采用以下方式避免：

- 使用一个足够大但不会在加法中溢出的值；
- 在相加前判断该值是否表示无穷大；
- 使用更大的整数类型，例如 `long long` 或 `long`。

Python 的整数可以自动扩展，通常不会发生固定长度整数溢出，而且本题代码使用的是 `float("inf")`，因此不存在这个问题。

## 解法对比

| 解法         | 时间复杂度     | 空间复杂度 | 特点                           |
| ------------ | -------------- | ---------- | ------------------------------ |
| 普通递归     | \(O(2^{m+n})\) | \(O(m+n)\) | 容易理解，但存在大量重复计算   |
| 记忆化搜索   | \(O(mn)\)      | \(O(mn)\)  | 保留递归结构，同时避免重复计算 |
| 二维动态规划 | \(O(mn)\)      | \(O(mn)\)  | 无递归开销，状态关系直观       |
| 一维动态规划 | \(O(mn)\)      | \(O(n)\)   | 时间最优，同时节省空间         |

面试中通常建议先说明二维动态规划的状态定义和转移方程，再根据要求给出一维空间优化版本。
