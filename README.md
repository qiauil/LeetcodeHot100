# LeetCode Hot 100 题解

本仓库整理了 [LeetCode Hot 100](https://leetcode.cn/studyplan/top-100-liked/) 题单的中文解析，按 LeetCode 题目难度分类，旨在帮助学习者理解常见算法、数据结构和解题模式。

## 内容

| 难度 | 题目数 | 详细题解 | 速查表 |
| --- | ---: | --- | --- |
| 简单 | 20 | [`easy/questions`](easy/questions/) | [`easy/cheatsheet.md`](easy/cheatsheet.md) |
| 中等 | 68 | [`medium/questions`](medium/questions/) | [`medium/cheatsheet.md`](medium/cheatsheet.md) |
| 困难 | 12 | [`hard/questions`](hard/questions/) | [`hard/cheatsheet.md`](hard/cheatsheet.md) |

每道题的详细解析通常包含：

- 题目和示例的中文说明；
- 解题思路与推导过程；
- Python 参考代码；
- 时间、空间复杂度分析；
- 常见错误和相关知识点。

`cheatsheet.md` 保留了每道题最关键的破局点和代码模板，适合在复习或面试前快速回顾。

## 如何使用

1. 根据题目难度进入对应的 `questions` 目录。
2. 先自行尝试解题，再阅读题解中的思路和代码。
3. 完成一个阶段后，使用对应的 `cheatsheet.md` 巩固解题模式。
4. 将参考代码改写为自己能够独立解释和实现的版本。

## AI 生成声明

本仓库中的题目解析和参考代码由大语言模型（LLM）生成。

这些内容用于学习和参考，并非 LeetCode 官方题解。尽管已尽量保证内容的正确性，其中仍可能存在事实、逻辑、边界条件或复杂度分析方面的错误。请结合题目原文、实际运行结果和可信资料进行核验，不要将内容视为绝对正确的标准答案。
