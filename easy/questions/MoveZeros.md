# 移动零（Move Zeroes）

## 题目描述

给定一个数组 `nums`，将数组中的所有 `0` 移动到数组末尾，同时保持所有**非零元素原有的相对顺序**。

要求必须**原地修改数组（in-place）**，不能通过复制出一个新的数组来完成。

### 示例 1

```
输入：
nums = [0, 1, 0, 3, 12]

输出：
[1, 3, 12, 0, 0]
```

### 示例 2

```
输入：
nums = [0]

输出：
[0]
```

------

# 1. 核心思路：双指针（Two Pointers）

这道题最经典、最推荐的解法是使用**双指针**。

我们可以使用两个下标：

```
left
right
```

其中：

- `right`：负责从左到右扫描整个数组，寻找非零元素；
- `left`：表示“下一个非零元素应该放置的位置”。

核心思想可以理解为：

> `right` 负责寻找非零元素，`left` 负责安排非零元素应该去哪里。

例如：

```
nums = [0, 1, 0, 3, 12]
```

开始时：

```
left = 0
```

扫描到 `1` 时：

```
[0, 1, 0, 3, 12]
 ↑  ↑
left right
```

`1` 应该移动到 `left` 所指向的位置。

处理后：

```
[1, 0, 0, 3, 12]
    ↑
   left
```

然后继续寻找下一个非零元素。

最终：

```
[1, 3, 12, 0, 0]
```

------

# 2. 推荐解法：双指针 + 交换

## 算法思路

维护两个指针：

```
left = 0
```

然后让 `right` 遍历整个数组。

当：

```
nums[right] != 0
```

时，说明发现了一个非零元素。

此时：

```
nums[left], nums[right] = nums[right], nums[left]
```

把这个非零元素交换到 `left` 的位置。

然后：

```
left += 1
```

因为这个位置已经正确放置了一个非零元素。

------

## 代码

```
from typing import List


class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        # left 表示下一个非零元素应该放置的位置
        left = 0

        # right 从左到右扫描整个数组
        for right in range(len(nums)):
            # 找到一个非零元素
            if nums[right] != 0:
                # 将非零元素放到 left 所指向的位置
                nums[left], nums[right] = nums[right], nums[left]

                # 下一个非零元素应该放在下一个位置
                left += 1
```

注意，这道题通常要求**直接修改 `nums`**，因此函数不需要返回数组。

# 3. 执行过程分析

以：

```
nums = [0, 1, 0, 3, 12]
```

为例。

初始状态：

```
nums = [0, 1, 0, 3, 12]

left = 0
```

------

## 第一次扫描

```
right = 0
nums[right] = 0
```

因为当前元素是 `0`，什么都不做。

```
[0, 1, 0, 3, 12]
 ↑
left
right
```

此时：

```
left = 0
```

------

## 第二次扫描

```
right = 1
nums[right] = 1
```

发现非零元素。

```
[0, 1, 0, 3, 12]
 ↑  ↑
 L  R
```

交换：

```
nums[0], nums[1] = nums[1], nums[0]
```

得到：

```
[1, 0, 0, 3, 12]
```

然后：

```
left = 1
```

------

## 第三次扫描

```
right = 2
nums[right] = 0
```

什么都不做。

```
[1, 0, 0, 3, 12]
    ↑  ↑
    L  R
```

------

## 第四次扫描

```
right = 3
nums[right] = 3
```

发现非零元素：

```
[1, 0, 0, 3, 12]
    ↑     ↑
    L     R
```

交换：

```
nums[1], nums[3] = nums[3], nums[1]
```

得到：

```
[1, 3, 0, 0, 12]
```

然后：

```
left = 2
```

------

## 第五次扫描

```
right = 4
nums[right] = 12
```

交换：

```
nums[2], nums[4] = nums[4], nums[2]
```

得到：

```
[1, 3, 12, 0, 0]
```

最终：

```
left = 3
```

答案：

```
[1, 3, 12, 0, 0]
```

# 4. 为什么这种交换不会破坏非零元素的顺序？

这是这道题一个比较重要的地方。

假设：

```
nums = [0, 4, 0, 2, 0, 7]
```

非零元素原本的顺序是：

```
4 → 2 → 7
```

`right` 是**从左向右**扫描的，因此发现非零元素的顺序一定也是：

```
4 → 2 → 7
```

而 `left` 同样是从左向右递增的：

```
0 → 1 → 2
```

因此这些非零元素会依次被放到：

```
nums[0] = 4
nums[1] = 2
nums[2] = 7
```

最终：

```
[4, 2, 7, 0, 0, 0]
```

所以非零元素之间的相对顺序不会发生变化。

这种性质通常称为：

> **Stable（稳定）**

也就是说，这个算法在移动元素之后仍然保持目标元素原来的相对顺序。

# 5. 双指针中两个指针分别代表什么？

理解双指针算法时，最好不要单纯记住：

```
left
right
```

而是理解两个指针的**语义**。

在这道题中：

### `right`

表示：

> 当前正在检查哪个元素。

它负责：

```
寻找下一个非零元素
```

------

### `left`

表示：

> 下一个非零元素应该被放在哪里。

因此可以记成：

```
right = 搜索指针
left  = 写入指针
```

或者：

```
right = read pointer
left  = write pointer
```

这其实是一种非常常见的双指针模式：

```
Read Pointer + Write Pointer
```

即：

> 一个指针负责读取数组，一个指针负责重新组织数组。

------

# 6. 为什么 `left` 只在遇到非零元素时移动？

代码：

```
if nums[right] != 0:
    nums[left], nums[right] = nums[right], nums[left]
    left += 1
```

注意：

```
left += 1
```

位于 `if` 内部。

这是因为 `left` 表示：

> 下一个非零元素应该放置的位置。

只有真正放置了一个非零元素后，这个位置才算被占用。

例如：

```
nums = [0, 0, 5]
```

开始：

```
left = 0
```

前两个 `0` 都不应该占用非零区域，因此：

```
left = 0
```

一直不变。

直到发现：

```
5
```

才把它移动到：

```
nums[0]
```

然后：

```
left = 1
```

------

# 7. Python 多变量交换说明

代码中：

```
nums[left], nums[right] = nums[right], nums[left]
```

是 Python 非常常见的交换写法。

例如：

```
a = 10
b = 20

a, b = b, a
```

执行后：

```
a = 20
b = 10
```

不需要像某些其他语言那样使用临时变量：

```
temp = a
a = b
b = temp
```

因此：

```
nums[left], nums[right] = nums[right], nums[left]
```

就是交换数组中的两个元素。

------

# 8. 时间与空间复杂度

## 时间复杂度

`right` 只遍历数组一次：

```
0 → 1 → 2 → ... → n - 1
```

因此时间复杂度为：

```
O(n)
```

------

## 空间复杂度

我们只使用了两个变量：

```
left
right
```

并没有创建与数组大小相关的新数组。

因此空间复杂度为：

```
O(1)
```

这也满足题目的：

```
原地修改数组
```

要求。

------

# 9. 另一种写法：先覆盖非零元素，再补零

除了交换，还可以采用一个非常直观的方法：

> 第一次遍历把所有非零元素依次写到数组前面，然后把剩余位置全部填写为 `0`。

例如：

```
[0, 1, 0, 3, 12]
```

先提取非零元素：

```
[1, 3, 12, ?, ?]
```

然后后面全部填写 `0`：

```
[1, 3, 12, 0, 0]
```

## 代码

```
from typing import List


class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        # write 表示下一个非零元素应该写入的位置
        write = 0

        # 第一遍：将所有非零元素移动到数组前面
        for num in nums:
            if num != 0:
                nums[write] = num
                write += 1

        # 第二步：
        # 从 write 开始，剩余位置全部填 0
        while write < len(nums):
            nums[write] = 0
            write += 1
```

------

# 10. 两种写法的区别

| 方法                | 时间复杂度 | 空间复杂度 | 特点                 |
| ------------------- | ---------- | ---------- | -------------------- |
| 双指针 + 交换       | O(n)       | O(1)       | 一次遍历，经典双指针 |
| 覆盖非零元素 + 补零 | O(n)       | O(1)       | 思路非常直观         |

两种方法都符合题目要求。

在代码面试中，我更推荐掌握：

```
双指针 + 交换
```

因为它很好地体现了经典的：

```
Read Pointer + Write Pointer
```

双指针思想。

# 11. 一个小优化：避免自己和自己交换

原来的代码：

```
if nums[right] != 0:
    nums[left], nums[right] = nums[right], nums[left]
    left += 1
```

当数组前面本来就是非零元素时：

```
nums = [1, 2, 0, 3]
```

开始：

```
left = 0
right = 0
```

会执行：

```
nums[0], nums[0] = nums[0], nums[0]
```

虽然完全正确，但这次交换没有实际意义。

可以增加：

```
if left != right:
```

避免无意义的交换。

```
from typing import List


class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        left = 0

        for right in range(len(nums)):
            if nums[right] != 0:
                # 只有两个位置不同时才真正交换
                if left != right:
                    nums[left], nums[right] = nums[right], nums[left]

                left += 1
```

不过从算法复杂度来看：

```
O(n)
```

并没有变化。

在面试中，通常不必刻意做这个优化，除非面试官进一步询问如何减少写操作。

# 12. 常见错误

## 1. 创建新的数组

例如：

```
result = []

for num in nums:
    if num != 0:
        result.append(num)
```

然后再添加 `0`。

虽然逻辑上可以得到正确答案，但是额外使用了：

```
O(n)
```

空间。

题目明确要求：

> 不复制数组，原地修改。

因此不是理想解法。

------

## 2. 删除 `0` 再追加

可能会想到：

```
for num in nums:
    if num == 0:
        nums.remove(0)
        nums.append(0)
```

这种写法有两个问题。

首先，在遍历数组的同时修改数组长度或结构，很容易导致元素被跳过。

其次：

```
list.remove()
```

本身可能需要移动大量元素，时间复杂度是 `O(n)`。

如果在循环中重复调用，整体可能退化为：

```
O(n²)
```

因此不推荐。

------

## 3. 忘记保持非零元素的相对顺序

题目不仅要求：

```
0 全部移动到末尾
```

还要求：

```
非零元素保持原来的相对顺序
```

例如：

```
[0, 5, 0, 2, 7]
```

正确：

```
[5, 2, 7, 0, 0]
```

但：

```
[7, 2, 5, 0, 0]
```

虽然也把所有 `0` 放到了最后，却不满足题目要求。

------

## 4. 错误地认为要返回数组

LeetCode 中这道题的函数通常是：

```
def moveZeroes(self, nums: List[int]) -> None:
```

返回类型是：

```
None
```

也就是说，应该：

```
直接修改 nums
```

而不是：

```
return nums
```

当然，在本地测试时打印 `nums` 是没有问题的。

# 13. 面试中的推荐写法

```
from typing import List


class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        left = 0

        for right in range(len(nums)):
            if nums[right] != 0:
                nums[left], nums[right] = nums[right], nums[left]
                left += 1
```

面试时可以这样解释：

> 我使用两个指针。`right` 从左到右扫描数组，负责寻找非零元素；`left` 表示下一个非零元素应该放置的位置。每当 `right` 找到非零元素，就把它交换到 `left` 的位置，然后移动 `left`。因为非零元素是按照原数组从左到右被处理的，所以它们的相对顺序不会改变。整个数组只需要扫描一次，因此时间复杂度是 `O(n)`，同时只使用常数额外空间，所以空间复杂度是 `O(1)`。

------

# 14. 算法总结

这道题真正值得掌握的是一种非常常见的双指针模式：

```
快指针 / 读指针
        ↓
遍历并寻找“有效元素”

慢指针 / 写指针
        ↓
维护下一个有效元素应该放置的位置
```

可以抽象为：

```
原数组
      ↓
right 不断扫描
      ↓
遇到符合条件的元素
      ↓
放到 left 的位置
      ↓
left += 1
```

对于本题：

```
有效元素 = 非零元素
```

于是数组逐渐被划分成：

```
[ 已整理好的非零元素 | 尚未处理的区域 ]
```

处理结束后自然变成：

```
[ 所有非零元素 | 所有 0 ]
```

这种 **Read Pointer + Write Pointer** 的思想会大量出现在数组原地修改题目中，例如：

- 原地删除某些元素；
- 删除有序数组中的重复项；
- 按条件移动数组元素；
- 数组压缩；
- 保持相对顺序的原地过滤。

因此相比记住这道题的代码，更重要的是记住：

> **当题目要求“原地修改数组，同时筛选或移动某类元素”时，可以优先考虑一个指针负责扫描、另一个指针负责记录写入位置。**
