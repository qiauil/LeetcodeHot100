# First Missing Positive（缺失的第一个正整数）

## 题目描述

给定一个**未排序的整数数组** `nums`，返回数组中**没有出现的最小正整数**。

要求：

- 时间复杂度必须为 `O(n)`
- 额外空间复杂度必须为 `O(1)`

### 示例 1

```
输入：nums = [-2, -1, 0]
输出：1
```

### 示例 2

```
输入：nums = [1, 2, 4]
输出：3
```

### 示例 3

```
输入：nums = [1, 2, 4, 5, 6, 3, 1]
输出：7
```

### 约束

```
1 <= nums.length <= 100,000
-(2^31) <= nums[i] <= 2^31 - 1
```

------

# 一、核心观察：答案一定在 `[1, n + 1]`

这是这道题最重要的性质。

假设数组长度为 `n`。

我们只需要关心：

```
1, 2, 3, ..., n
```

如果其中某个数字缺失，那么答案一定不超过 `n`。

如果 `1 ~ n` 全部出现，那么：

```
答案 = n + 1
```

例如：

```
nums = [1, 2, 3, 4]
n = 4

1 ~ 4 全部存在
所以答案 = 5
```

因此：

```
First Missing Positive ∈ [1, n + 1]
```

这也是后面能够做到 `O(n)` 时间、`O(1)` 额外空间的关键。

------

# 二、方法 1：暴力枚举

## 思路

最直观的方法是：

从 `1` 开始，依次检查：

```
1 是否存在？
2 是否存在？
3 是否存在？
...
```

对于每一个候选数字，都遍历整个数组。

第一次找不到的正整数就是答案。

例如：

```
nums = [1, 2, 4]
```

检查：

```
1 -> 存在
2 -> 存在
3 -> 不存在
```

因此：

```
答案 = 3
```

## 算法步骤

1. 初始化 `missing = 1`

2. 遍历数组，检查 `missing` 是否存在

3. 如果存在：

   ```
   missing += 1
   ```

4. 如果不存在，直接返回 `missing`

## Python 代码

```
class Solution:
    def firstMissingPositive(self, nums: list[int]) -> int:
        missing = 1

        while True:
            found = False

            # 在整个数组中寻找 missing
            for num in nums:
                if num == missing:
                    found = True
                    break

            # 如果 missing 没有出现，它就是答案
            if not found:
                return missing

            missing += 1
```

## 复杂度

时间复杂度：

```
O(n²)
```

因为最多检查 `1 ~ n + 1`，而每次检查都可能扫描整个数组。

空间复杂度：

```
O(1)
```

## 评价

优点：

- 思路最简单
- 很容易写对

缺点：

- 不满足题目的 `O(n)` 时间复杂度要求

因此一般只适合作为最初的思路。

------

# 三、方法 2：Boolean Array / 哈希思想

## 思路

因为答案只可能出现在：

```
[1, n + 1]
```

所以实际上我们只需要记录：

```
1 ~ n
```

是否出现。

可以创建一个长度为 `n` 的布尔数组：

```
seen = [False] * n
```

规定：

```
seen[0] 表示数字 1 是否出现
seen[1] 表示数字 2 是否出现
seen[2] 表示数字 3 是否出现
...
seen[i] 表示数字 i + 1 是否出现
```

例如：

```
nums = [1, 2, 4]
```

得到：

```
seen = [True, True, False]
```

第一个 `False` 的位置是：

```
index = 2
```

对应数字：

```
2 + 1 = 3
```

所以答案是 `3`。

------

## 算法步骤

1. 创建长度为 `n` 的数组 `seen`
2. 遍历 `nums`
3. 如果：

```
1 <= num <= n
```

则标记：

```
seen[num - 1] = True
```

1. 从左到右寻找第一个 `False`
2. 如果 `seen[i] == False`：

```
答案 = i + 1
```

1. 如果全部都是 `True`：

```
答案 = n + 1
```

------

## Python 代码

```
class Solution:
    def firstMissingPositive(self, nums: list[int]) -> int:
        n = len(nums)

        # seen[i] 表示数字 i + 1 是否出现
        seen = [False] * n

        for num in nums:
            # 只需要关心 1 ~ n
            if 1 <= num <= n:
                seen[num - 1] = True

        # 找第一个没有出现的数字
        for i in range(n):
            if not seen[i]:
                return i + 1

        # 如果 1 ~ n 全部存在
        return n + 1
```

------

## 复杂度

时间复杂度：

```
O(n)
```

空间复杂度：

```
O(n)
```

------

## 评价

这个方法实际上已经非常接近最终答案。

它使用了一个额外数组作为：

```
value -> 是否出现
```

的映射。

真正的难点是：

> 能不能不创建 `seen` 数组，而直接利用 `nums` 本身完成这个映射？

后面的两种 `O(1)` 空间方法，本质上都在解决这个问题。

------

# 四、方法 3：排序

## 思路

如果数组有序，问题会简单很多。

排序之后，我们维护：

```
missing = 1
```

表示：

> 当前正在寻找的最小正整数。

如果遇到：

```
num == missing
```

说明当前数字存在，于是：

```
missing += 1
```

对于：

- 负数
- `0`
- 重复数字

都可以直接忽略。

------

## 示例

```
nums = [3, 4, -1, 1]
```

排序：

```
[-1, 1, 3, 4]
```

初始化：

```
missing = 1
```

扫描：

```
-1 -> 忽略

1 == missing
missing = 2

3 != 2
4 != 2
```

最终：

```
答案 = 2
```

------

## Python 代码

```
class Solution:
    def firstMissingPositive(self, nums: list[int]) -> int:
        nums.sort()

        missing = 1

        for num in nums:
            # 找到当前正在等待的数字
            if num == missing:
                missing += 1

        return missing
```

这里实际上不需要显式判断：

```
num > 0
```

因为 `missing` 永远是正数，所以负数自然不会和它相等。

------

## 复杂度

时间复杂度：

```
O(n log n)
```

空间复杂度：

```
取决于排序实现
```

对于 Python：

```
list.sort()
```

使用的是 **Timsort**。

严格来说，它并不能保证 `O(1)` 额外空间，因此这个方法同样不符合题目的最终要求。

# 五、方法 4：负数标记 Negative Marking

这是一个满足题目要求的解法：

```
时间：O(n)
额外空间：O(1)
```

------

## 核心思想

我们希望直接把数组本身当作 `seen` 数组。

建立这样的对应关系：

```
数字 1 -> nums[0]
数字 2 -> nums[1]
数字 3 -> nums[2]
...
数字 k -> nums[k - 1]
```

然后通过某种方式记录：

```
数字 k 出现过
```

这里使用：

```
nums[k - 1] < 0
```

作为标记。

也就是说：

```
nums[i] 是负数
```

表示：

```
数字 i + 1 出现过
```

------

# 六、为什么需要先处理非正数？

原数组可能本身包含：

```
负数
0
```

例如：

```
[-1, 1, 3, 4]
```

如果直接把“负数”当作出现标记，就无法判断：

```
这个负数原本就是负数
```

还是：

```
它是我们后来人为标记成负数的
```

所以第一步必须把原来的非正数消除掉。

原答案只将：

```
nums[i] < 0
```

变成 `0`。

这样也是可行的，因为 `0` 本身不是正整数。

```
for i in range(len(nums)):
    if nums[i] < 0:
        nums[i] = 0
```

也可以写成：

```
if nums[i] <= 0:
    nums[i] = 0
```

两者对最终逻辑没有本质区别。

------

# 七、如何用负号表示“出现过”？

假设：

```
nums = [1, 2, 4]
```

长度：

```
n = 3
```

处理数字 `1`：

```
目标位置 = 1 - 1 = 0
```

于是把：

```
nums[0]
```

改成负数。

处理数字 `2`：

```
目标位置 = 2 - 1 = 1
```

把：

```
nums[1]
```

改成负数。

最后：

```
index 0 为负 -> 1 存在
index 1 为负 -> 2 存在
index 2 非负 -> 3 不存在
```

答案：

```
3
```

------

# 八、为什么需要 `abs()`？

这是负数标记法最容易出错的地方之一。

假设原数组：

```
[1, 2, 3]
```

处理 `1` 后：

```
[-1, 2, 3]
```

当之后遍历到这个位置时：

```
nums[i]
```

可能已经被修改。

但是我们仍然需要知道它原本代表的值。

因此使用：

```
val = abs(nums[i])
```

例如：

```
-1 -> abs(-1) -> 1
```

这样可以恢复原始数字。

------

# 九、为什么 `0` 需要特殊处理？

通常我们通过：

```
nums[index] *= -1
```

来标记。

但：

```
0 * -1 = 0
```

所以：

```
0
```

无法通过取负变成“已出现”的标记。

因此需要一个特殊负数。

例如：

```
-(n + 1)
```

因为：

```
n + 1
```

本身超出了我们需要关心的 `[1, n]` 范围。

所以可以安全地使用：

```
-(n + 1)
```

作为：

```
这个位置原本是 0，但已经被标记
```

------

# 十、Negative Marking 完整代码

```
class Solution:
    def firstMissingPositive(self, nums: list[int]) -> int:
        n = len(nums)

        # 第一步：
        # 消除原数组中的负数，避免它们和我们的“负号标记”冲突
        for i in range(n):
            if nums[i] < 0:
                nums[i] = 0

        # 第二步：
        # 使用 nums[val - 1] 的正负号表示 val 是否出现
        for i in range(n):
            # nums[i] 可能已经被前面的操作变成负数，
            # 所以需要用 abs() 获取原始值
            val = abs(nums[i])

            if 1 <= val <= n:
                index = val - 1

                if nums[index] > 0:
                    # 变成负数，表示 val 出现过
                    nums[index] *= -1

                elif nums[index] == 0:
                    # 0 取负仍然是 0，所以使用特殊负值
                    nums[index] = -(n + 1)

        # 第三步：
        # 第一个非负位置代表对应数字没有出现
        for i in range(n):
            if nums[i] >= 0:
                return i + 1

        # 1 ~ n 全部出现
        return n + 1
```

------

# 十二、方法 5：Cyclic Sort / 原地哈希

这是另一种更经典、更直观的 `O(n) + O(1)` 解法。

个人建议面试时优先掌握这一种。

------

## 核心思想

对于数字：

```
1 ~ n
```

它们都有一个“应该出现的位置”：

```
数字 1 应该放在 index 0
数字 2 应该放在 index 1
数字 3 应该放在 index 2
...
数字 x 应该放在 index x - 1
```

因此我们尽量把每一个合法数字放到：

```
nums[num - 1]
```

的位置。

最终希望数组变成：

```
[1, 2, 3, 4, ...]
```

至少合法数字应该尽可能位于自己的位置。

然后扫描数组：

```
第一个 nums[i] != i + 1
```

的位置就是答案。

------

# 十三、Cycle Sort 示例

例如：

```
nums = [3, 4, -1, 1]
```

我们希望：

```
1 -> index 0
2 -> index 1
3 -> index 2
4 -> index 3
```

开始：

```
[3, 4, -1, 1]
```

当前位置：

```
i = 0
nums[i] = 3
```

`3` 应该放在：

```
index = 3 - 1 = 2
```

交换：

```
[-1, 4, 3, 1]
```

此时：

```
nums[0] = -1
```

不合法，进入下一位置。

------

`i = 1`：

```
nums[1] = 4
```

`4` 应该在：

```
index 3
```

交换：

```
[-1, 1, 3, 4]
```

当前位置现在变成 `1`。

`1` 应该放到：

```
index 0
```

交换：

```
[1, -1, 3, 4]
```

最终：

```
[1, -1, 3, 4]
```

扫描：

```
index 0 -> nums[0] = 1 ✓

index 1 -> nums[1] = -1
           但这里应该是 2
```

因此：

```
答案 = 2
```

------

# 十四、Cycle Sort 算法

对于每一个位置 `i`：

如果：

```
1 <= nums[i] <= n
```

那么它应该去：

```
target = nums[i] - 1
```

如果目标位置还不是这个数字：

```
nums[i] != nums[target]
```

就交换：

```
nums[i], nums[target] = nums[target], nums[i]
```

注意：

> 交换以后不能立刻 `i += 1`。

因为交换过来的新数字可能仍然需要继续移动。

------

# 十五、Cycle Sort 完整代码

```
class Solution:
    def firstMissingPositive(self, nums: list[int]) -> int:
        n = len(nums)
        i = 0

        # 第一阶段：
        # 尽量把数字 x 放到 index x - 1
        while i < n:
            # 不在 [1, n] 范围内的数字不需要处理
            if nums[i] <= 0 or nums[i] > n:
                i += 1
                continue

            # nums[i] 应该放置的位置
            target = nums[i] - 1

            if nums[i] != nums[target]:
                # 将当前数字放到它正确的位置
                nums[i], nums[target] = nums[target], nums[i]

                # 注意：
                # 此处不能 i += 1
                # 因为交换过来的 nums[i] 可能仍然需要继续处理
            else:
                # 已经处于正确位置，或者遇到重复数字
                i += 1

        # 第二阶段：
        # 第一个位置和值不匹配的地方就是答案
        for i in range(n):
            if nums[i] != i + 1:
                return i + 1

        # 如果 1 ~ n 全部存在
        return n + 1
```

------

# 十六、为什么 Cycle Sort 是 `O(n)`，而不是 `O(n²)`？

代码中有一个：

```
while
```

并且某些位置可能交换很多次，看起来似乎可能达到 `O(n²)`。

但实际上不会。

关键在于：

> 每次有效交换，至少会把一个数字放到它最终正确的位置。

例如：

```
数字 5
```

一旦被放到：

```
nums[4]
```

之后通常就不会再被移动。

数组中只有 `n` 个位置，因此有效交换次数最多是 `O(n)`。

所以整个算法：

```
O(n)
```

这属于一种常见的 **amortized analysis（摊还分析）**。

------

# 十七、为什么一定要判断重复数字？

这一条件非常重要：

```
nums[i] != nums[target]
```

考虑：

```
nums = [1, 1]
```

当：

```
i = 1
nums[i] = 1
```

它想去：

```
target = 0
```

但：

```
nums[0] == 1
```

如果仍然交换：

```
1 <-> 1
```

数组不会发生任何变化。

然后代码再次循环：

```
1 <-> 1
1 <-> 1
1 <-> 1
...
```

造成死循环。

因此必须检查：

```
nums[i] != nums[nums[i] - 1]
```

只有目标位置不是相同数字时才交换。

------

# 十八、为什么不需要处理 `n + 1` 以上的数字？

例如：

```
nums = [1, 2, 100000]
```

长度：

```
n = 3
```

答案只可能是：

```
1, 2, 3, 4
```

因此：

```
100000
```

完全没有意义，可以直接忽略。

这是整个问题最重要的剪枝思想：

```
if nums[i] <= 0 or nums[i] > n:
    ignore
```

------

# 十九、两种最优方法对比

| 方法             | 时间         | 额外空间   | 是否修改数组 | 推荐程度     |
| ---------------- | ------------ | ---------- | ------------ | ------------ |
| 暴力             | `O(n²)`      | `O(1)`     | 否           | 不推荐       |
| Boolean Array    | `O(n)`       | `O(n)`     | 否           | 容易理解     |
| 排序             | `O(n log n)` | 取决于排序 | 是           | 一般         |
| Negative Marking | `O(n)`       | `O(1)`     | 是           | 推荐         |
| Cycle Sort       | `O(n)`       | `O(1)`     | 是           | **非常推荐** |

------

# 二十、面试中推荐的思考路径

这道题真正考察的往往不是直接写出 Cycle Sort，而是能不能一步一步优化。

一个很自然的推导过程是：

```
暴力搜索
    ↓
每个数字都扫描数组
O(n²)

使用 HashSet / Boolean Array
    ↓
快速判断一个数字是否出现
O(n) time
O(n) space

发现答案只在 [1, n + 1]
    ↓
只需要记录 1 ~ n

能不能把 nums 本身作为 Hash Table？
    ↓
value x 映射到 index x - 1

Negative Marking / Cycle Sort
    ↓
O(n) time
O(1) space
```

在面试中，这种推导过程通常比单纯背出最终答案更加重要。

# 二十一、Python 语法与函数说明

## 1. `abs()`

```
abs(x)
```

返回数字的绝对值。

例如：

```
abs(-5)   # 5
abs(5)    # 5
abs(0)    # 0
```

在 Negative Marking 中非常重要：

```
val = abs(nums[i])
```

因为 `nums[i]` 可能已经被我们修改成负数。

------

## 2. `range()`

例如：

```
range(n)
```

产生：

```
0, 1, 2, ..., n - 1
```

所以：

```
for i in range(n):
```

相当于遍历数组的所有下标。

而：

```
range(1, n + 1)
```

产生：

```
1, 2, ..., n
```

------

## 3. Python tuple unpacking 交换

Cycle Sort 中：

```
nums[i], nums[target] = nums[target], nums[i]
```

是 Python 常用的交换写法。

例如：

```
a = 1
b = 2

a, b = b, a
```

之后：

```
a = 2
b = 1
```

不需要额外变量：

```
temp
```

从算法分析角度看，这仍然属于：

```
O(1)
```

额外空间。

------

## 4. `list[int]`

```
nums: list[int]
```

是 Python 的类型提示（type hint）。

表示：

```
nums 是一个 list
其中的元素应该是 int
```

例如：

```
def firstMissingPositive(self, nums: list[int]) -> int:
```

表示：

```
输入：整数列表
返回：整数
```

如果是较老版本的 Python，LeetCode 中也经常见到：

```
from typing import List

def firstMissingPositive(self, nums: List[int]) -> int:
```

二者用途基本相同。

# 二十二、常见错误

## 1. 忘记答案最大只有 `n + 1`

必须牢记：

```
答案 ∈ [1, n + 1]
```

如果：

```
nums = [1, 2, ..., n]
```

答案就是：

```
n + 1
```

因此完全不需要处理：

```
> n
```

的大整数。

------

## 2. 没有正确处理负数和 0

数组可能包含：

```
负数
0
重复元素
超大正整数
```

例如：

```
[-5, 0, 1, 1, 10000]
```

Cycle Sort 中必须首先判断：

```
1 <= nums[i] <= n
```

否则：

```
nums[nums[i] - 1]
```

可能访问非法下标。

------

## 3. Cycle Sort 中重复数字导致死循环

错误写法：

```
while 1 <= nums[i] <= n:
    target = nums[i] - 1
    nums[i], nums[target] = nums[target], nums[i]
```

对于：

```
[1, 1]
```

会不断交换：

```
1 和 1
```

造成死循环。

必须增加：

```
nums[i] != nums[target]
```

------

## 4. Cycle Sort 交换以后错误地移动 `i`

错误：

```
nums[i], nums[target] = nums[target], nums[i]
i += 1
```

交换以后：

```
nums[i]
```

变成了新的数字。

这个新数字可能仍然需要移动，因此应该继续处理当前 `i`。

只有：

- 当前数字非法
- 已经放对位置
- 遇到重复元素

时，才：

```
i += 1
```

------

## 5. Negative Marking 忘记使用 `abs()`

错误：

```
val = nums[i]
```

因为这个位置可能之前已经被改成负数。

正确：

```
val = abs(nums[i])
```

------

## 6. Negative Marking 直接对 `0` 取负

```
0 * -1 == 0
```

所以：

```
0
```

无法通过符号进行标记。

需要使用特殊负值，例如：

```
-(n + 1)
```

------

# 二十三、面试最推荐版本

如果只准备一个最终解法，我推荐记住 **Cycle Sort / Index Placement** 版本：

```
class Solution:
    def firstMissingPositive(self, nums: list[int]) -> int:
        n = len(nums)

        # 把每个合法数字 x 放到 nums[x - 1]
        i = 0
        while i < n:
            if 1 <= nums[i] <= n:
                target = nums[i] - 1

                # 只有目标位置不是相同数字时才交换，
                # 防止重复元素导致死循环
                if nums[i] != nums[target]:
                    nums[i], nums[target] = nums[target], nums[i]
                    continue

            i += 1

        # 找第一个没有放对的位置
        for i in range(n):
            if nums[i] != i + 1:
                return i + 1

        return n + 1
```

它背后的核心模型可以记成一句话：

```
对于范围 1 ~ n 中的数字 x，
让数字 x 尽量待在下标 x - 1。
```

完成排列后：

```
nums[i] != i + 1
```

意味着：

```
数字 i + 1 不存在
```

这就是这道题最核心、也最值得掌握的思想。
